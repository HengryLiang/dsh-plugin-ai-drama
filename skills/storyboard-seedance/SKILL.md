# 智能分镜与 Seedance 2.5 提示词

## 〇、快速使用说明

**最简用法：把剧情丢进来就行。**

```
把这段拆成分镜：<你的剧情／小说片段／动作口述>
```

可选的补充信息，给了会更准，不给我会主动问或自己定：

| 你可以给 | 不给的话 |
|---|---|
| 分组时长（15 秒一组／30 秒一组） | 我按情绪拍段自己分，并告诉你怎么分的 |
| 参考图（人物／服装／场景／关键帧） | 只按文字建角色，一致性会弱 |
| 参考视频或上一条的截帧 | 无法接住上一镜末帧，需要你口述接续状态 |
| 素材 ID（Seedance 的图片／音色 ID） | 输出里用占位符，跑之前你要替换 |
| 特殊要求（一镜到底／必须硬切／指定机位） | 按剧情需要自行判断 |

**几种常用说法：**

- `这段没想好怎么拍，先给我几个方案` — 我会给二到三个分镜方向让你选，不直接开写
- `只改镜头 3` — 只输出那一条
- `完整给我` — 输出全组，保留所有已确认内容
- `接着上一条继续` — 请同时给我上一条的末帧截图或状态口述
- `跑出来 XX 不对` — 描述实际画面，我先定位是描述的问题还是模型的问题，再改

**我会主动做的事：**发现你的设定在物理或几何上不成立时先提出来，不闷头执行；发现某一镜的信息量装不下时建议拆条；发现景别接续违规时改机位并说明。

## 一、任务定位

把一段剧情改写成可交给 Seedance 2.5 的分镜提示词。分镜既要有叙事能力，也要克制、可执行——不为显得专业而堆砌模型无法同时完成的指令。

本 Skill 处理：小说正文、剧情口述、动作设计、人物图、场景图、关键帧、参考视频、逐镜修改意见。

**目标不是把文字平均拆开，而是找到剧情的视觉节拍：**建立关系、推进动作、强调转折、保留反应、完成落点。

---

## 二、主动引导

这个 Skill 不只被动执行。遇到以下情况，主动介入：

### 1. 创作者没有分镜思路时

不要直接开写。先做两件事：

**一，复述理解。**用三到五句话说清：这段发生了什么、谁在推动、情绪从哪儿开始到哪儿落。让对方确认理解没跑偏。

**二，给二到三个分镜方向，说明各自适合什么。**方向之间要有真实差异，不是同一个方案的三种措辞。常见的分岔：

- **克制的长镜 vs 碎切的紧张** — 前者靠停顿和表演，后者靠信息密度和方向感
- **跟着谁走** — 同一场戏跟着施压方拍是压迫，跟着承受方拍是恐惧
- **先给全貌还是先给局部** — 先全貌是交代，先局部是悬念
- **落点放在动作上还是放在反应上** — 决定最后一个镜头给谁

给方向时至少有一个是反直觉的，并说清它的风险。

### 2. 前提有问题时

**先反问，不要闷头执行。**常见的前提错误：

- **几何不成立** — 需要接触的动作（架刀、搀扶、递物），先算两人距离。够不着就是设定错了，不是模型执行错了。
- **姿态推不出机位** — 先把「受力方向 → 身体姿态 → 摄影机唯一可能的位置 → 这个位置看得见什么／看不见什么」推到底再动笔。画面里不可能出现的人，一个字都不要写。
- **信息量装不下** — 一个镜头里塞了五件事，建议拆条比压缩管用。
- **角色能力与动作矛盾** — 换了种族／形态之后，回头检查他原有的每个动作是否还属于这个形态（没有眼睑就不能眯眼，没有嘴就不能张口）。往往还能白赚一个更好的动作。

### 3. 反馈跑偏时

先定位是**描述的问题**还是**模型的问题**，再改。绝大多数是前者。定位方法见第十七章的诊断表。

## 三、最高优先级

前项高于后项：

1. 用户本轮最新修改
2. 用户已确认、明确要求保留的内容
3. 物理与几何的可能性
4. 人物、道具、环境、姿态与空间连续性
5. 参考图与参考视频各自承担的职责
6. 剧情因果、情绪节奏、表演准确性
7. 景别接续与非居中构图
8. 光影设计与影视质感
9. 焦段、景深、运镜
10. 视效规模、物理反馈、声音设计

「只改这个镜头」只输出该镜头；「完整给我」输出全组并保留所有已确认内容，不能在修复新问题时丢掉旧要求。

---

## 四、输出格式

除非另有要求，只用以下形式：

```markdown
【本组情绪总控】（一段全组通用提示词，见第十四章）

镜头1

85mm，侧方位平视……　光影：……　现场声：……

镜头2

35mm，机身从……　光影：……　现场声：……
```

规则：

- 按指定分组输出，每组配一段「本组情绪总控」，一组一处，全组共用
- 每个镜头写成一段连贯的自然语言，整合：焦段与景别／机位高度方位俯仰／主体在画幅中的位置与占比／前中后景／景深与焦点／运镜的起点路径速度终点／人物起点体态、动作、视线、情绪变化与结束体态／环境反应与视效
- **每个镜头必须有独立的「光影：」一句**（见第九章），描述光此刻怎么作用、以及光在这一镜的时间里怎么运动
- 每个镜头末尾一句「现场声：」，只写现场真实声源，绝无 BGM
- 台词逐字保留，另行标注
- 默认不写镜头时长、不给镜头起文学化标题、不拆成多字段模板

**为什么用自然语言而不用 JSON：**Seedance 2.5 对复杂结构化语言的处理能力很差，逐镜的独立字段表本身会被读成一张分镜表，在一镜到底的长条里尤其容易被当成切点。

## 五、生成前的内部工作流

1. **先理解剧情**，提炼发生了什么、谁在推动、观众先看见什么、情绪的起落，据此划分组。
2. **建立参考职责表**（见第六章）。
3. **建立体态台账**（见第八章）。
4. **提炼每组主情绪**（见第十四章）。
5. **规划景别序列**（见第十章）——在写任何一镜之前先把整组的景别排完，确认没有相邻接续。
6. **计算镜头数量与节奏**：情绪与对话允许长镜和停顿；信息转折用反应镜头或焦点转移；高燃动作用方向明确的快切与速度变化；单镜到底只设计一条连续路径。

## 六、参考材料职责表

不同参考只承担指定职责，不能串用：

| 参考类型 | 只负责 | 绝不带入 |
|---|---|---|
| 人物图 | 身份、面部、发型、年龄、体型、固有造型 | 它的姿势、机位、光、背景 |
| 服装图 | 服装结构、材质、配件 | 模特的姿势与体型 |
| 场景图 | 空间结构、天气、时间、色调、材质 | 它的机位与构图 |
| 特效图 | 能量颜色、形态、密度、尺度 | 它所在的场景 |
| 关键帧图 | 用户指定的机位、姿态、透视、构图 | 未指定的部分 |
| 参考视频 | 动作连续性、上一镜末帧、站位、速度、节奏 | — |

**两条常犯的错：**

- **把身份参照当成了编辑母版。**人设图只提供「这个人长什么样」；海报、分镜里的姿势、角度、光、背景全部重新设计。锁死母版姿势等于把三条自由度自己关掉了。
- **有参考图就闭嘴。**描述参考图里已有的东西＝诱导模型照搬那张图的构图。参考图只给身份与质感，构图与内容以文字为准。**但参考图给不了的两样必须留**：尺度（「只有他一个手掌那么大」）与场内关系（「他只到旁边那些人的腰那么高」）。

## 七、空间连续性引擎

### 1. 世界坐标与画面左右分开记

「A 在画面左侧」只说明当前机位下的屏幕位置，不等于 A 在真实空间里移动到了左边。反打可以让两人分别出现在不同的画面侧，但真实位置不变。

### 2. 继承上一镜末帧

下一镜第一帧必须继承：人物位置／朝向／视线、体态、手臂头部与武器位置、道具持有者与使用手、环境破坏与烟尘的阶段、已进入或离开画面的人。

### 3. 轴线管理

连续正反打默认留在轴线同一侧。换轴只允许：镜头在同一镜内清楚越过轴线／用正面或背面的中性镜头重建空间／人物自身完成可见转向／用户明确要求。

**反打导致的左右互换不是跳轴。**从对面拍，左右当然是反的，这是几何必然。但要在提示词里向模型解释清楚：「机位站在两人中间那片空地的深处朝他们回拍，所以左右和上一镜是反过来的，这不是换了一边，是同一片空地从另一头看过来。」

### 4. 站位信息只写在它被看见的那一镜

**不要把站位做成全局声明。**全局块对每一镜都生效，会渗进只有一个人的特写里，模型要么往画幅里塞人，要么按那个排布重新摆机位。站位是场景信息，只写在真正拍到它的那一镜。

### 5. 数量与排他靠空间封闭，不靠负向词

要画面里只有三个人，写「他身后是空的地面和树干，再没有别的人」，而不是「不要出现更多人」。**负向点名等于把它种进去。**同理，数量要正向数一遍（「就是四个」），并把他们身后的位置占满。

### 6. 连续性风险句

高风险处用一句正向描述重新锁定，不在每镜机械重复：

> 「A 仍坐在桌子北侧，B 仍坐在对面的南侧，本镜只改变摄影机位置，两人的座位与距离保持不变。」

## 八、动态衔接一致性引擎

第七章管「在哪里」，本章管「以什么体态在那里」。

### 1. 体态台账

逐镜记录每个人的五项：**体态**（躺趴侧卧坐蹲跪站跑倒地腾空被控制）／**朝向**／**手与道具**／**伤势与痕迹**／**接触与负重**。

**铁律：下一镜的开始状态必须等于上一镜的结束状态。**

### 2. 过渡动作铁律

**体态变化绝不允许发生在切镜的缝隙里。**只有三种合法方式：在上一镜内完成／在下一镜内以原体态起幅并写出过渡动作／增加一个过渡镜头。

禁止：躺着切到坐着表演、跪着切到站着说话、被撞倒切到站好继续走、被按住切到自由活动、空手切到持物。

**任何机位变化都不能豁免这条。**

### 3. 每镜必写起点与结束体态

- 正确：「他仍跪在积水里，双手撑地——接续上一镜末帧。他缓缓抬头……镜头结束时他已跌坐在墙脚，背靠墙，储存器仍攥在右手。」
- 错误：「他抬头看着飞行器……」（起点体态丢失，模型会让他莫名站着）

### 4. 环境与群像也要衔接

群演一旦在前景明确了动作，下一镜不得复位或消失。爆炸、烟尘、火焰、积水按时间继续演化，不得重置。

## 九、光影设计

**每一个镜头都必须有独立的光影描述。**这是最容易被跳过、也最决定成片质感的一栏。

### 1. 光影一栏必写两件事

**一，光此刻在画面里怎么作用**——落在哪、穿过什么、把什么照亮、把什么留在暗里。

**二，光在这一镜的时间里怎么运动**——没有任何一个镜头的光可以是静止的。

### 2. 光的运动要挂在别的东西的运动上

不要写「光自己在动」，写：

- 风推树冠，地上的亮斑一块一块移过去，边缘一直在变形
- 每一只脚踏进水洼，那片反光被踩碎，脚抬走后从碎的一点一点变回完整的一片
- 队伍站着不动，是光从他们身上移过去
- 他往前顶的时候整张脸进了亮斑，顶回来又退回一半在暗部，一进一退跟着他说话的节奏

### 3. 写光之前先算遮挡物

**遮挡物的粗细与距地距离决定光斑的软硬。**

- 又厚又近（窗棂、栅栏、墙缝）→ 硬边光柱，界线清楚
- 又细又远（树叶、气根、藤蔓）→ 边缘全化开，只剩不规则的斑，形不成清楚的条

写反了就出成舞台射灯，假。

### 4. 光本身不带颜色

叶子把光滤过之后是**被照透的叶子在亮**，不是光柱是绿的。写有色光柱＝出图变成染色滤镜。

正确：「最外圈那几层叶子被从后面照透，叶片本身亮成半透明的黄绿，看得见叶脉。」

### 5. 大而低的遮挡本身是巨大的柔光源

宽而低的树冠底下应该是整片柔和的暗＋零星叶隙光斑（大小不一、形状不规则、边缘化开、风推树冠时一块合上另一块张开），不是一堆清楚的竖缝。

### 6. 逆光的三条

- **亮线长在外缘，不长在面上。**把那条线的走向逐点写死（从额头、鼻梁、鼻尖、嘴唇一直到下巴、下颌、脖子，一路连着没有断过）
- **线以内整片压暗**，明写看不出五官，是一片没有细节的深色
- **发饰配件只在朝着光源的那一边亮出几个很小的点**，绝不写「反着光一闪一闪」

**自检问句：如果这条是逆光，那么描述里每一处「亮」，都必须能指出它长在哪条外轮廓线上；指不出来的亮，就是凭空加的一盏灯。**

### 7. 极亮背景上没有边缘光

主体压在极亮的圆盘或天空上时，它只能是纯黑的一块，一丝轮廓亮线也不会有——边缘光需要背景比主体暗才看得见。这两种状态互斥，写在一起模型只能二选一。

此时形状靠**负形**读：「叉与叉之间的空隙里是明亮的圆盘，角是从洞的形状读出来的，不是从任何高光读出来的。」

### 8. 需要提高可读性时，加背景亮度差，不要给主体补正面光

逆光人像脸太暗时，正确的加码是**加强背景亮度**，用亮度差把轮廓衬清楚；给正面补光会直接毁掉逆光。

## 十、景别接续

### 1. 景别阶梯

**大特写 — 特写 — 近景 — 中景 — 全景 — 大全景**

### 2. 相邻两级不许直接接

同一个主体的两个镜头之间必须跳一级以上。特写不能接近景，近景不能接特写和中景。

### 3. 唯一例外：视点主体切换

上一镜特写 A，下一镜特写 B，成立。换主体时允许相邻，也允许同级。

### 4. 越肩镜按最近处主体算景别

越肩镜的前景是肩和后脑（近景），视觉核心在远处。**按最近处主体算，不按视觉核心算。**否则接续判断会全错。

### 5. 复合镜内部的景别变化不算切

同一镜内靠机身与人的距离变化产生的景别变化不是新镜头，但要写成连续爬：「一点一点靠过去，靠得几乎察觉不到，没有哪一下突然近了一截，也没有到位落定这回事。」

**一条 clip 里景别若从头到尾不变，通常是素的；但景别的变化只许靠距离在变，不许靠换机位。**

## 十一、构图

### 1. 非居中是默认，居中是特例

每一镜的主体都不放在画幅正中。每一镜的偏置方向与上一镜相反。

**中心构图只用于：**仪式、审判、宣告、绝对权力、宿命对峙、正面威胁、时间静止、死亡、顿悟，或用户明确要求。

### 2. 不居中靠实体占位，不靠留白

**这是本章最要紧的一条。**空着的一侧模型会自动把主体挪回中间去填；另一侧站着一个具体的实体，主体就没地方回去了。

可执行写法：

> 「他的头压在画幅右侧、占右边三分之二，眼睛落在右上三分点附近。画幅左边三分之一被他身后一个队员的肩背占住，虚焦、只剩一块暗形状。」

### 3. 主体占比不能写「占画幅一大半」

**主体占一大半，物理上就回不到偏心位置。**这句话跟不居中直接互斥。改写成「占那一侧的三分之二，另外三分之一归实体和背景」。

### 4. 前景必须承担功能

前景是这个机位的定义（过肩俯拍里摊主的肩背、大腿高度那一排货物），换掉就不成立；杂物是换一个也不影响构图的东西。**不要为了填满规则请路人扛着不同东西轮流从最近处走过。**

**前景物的合法性取决于镜头的运动方式**：持续退拍的镜头里，能长时间留在最近处的只有跟镜头同向同速的东西。

### 5. 视觉路径

每镜内部确认四件事：观众的眼睛从哪里进入／前景或运动如何引导视线／视觉落点在哪里／动作或视线从哪个方向离开并如何接到下一镜。

每个画面只选一个主构图机制（压缩、对角线、框中框、前景遮挡、负空间、极端比例、反射），最多加一个辅助机制。

## 十二、焦段、景深与运镜

### 1. 焦段必须与画面范围相容

| 焦段 | 用途 |
|---|---|
| 18–24mm | 空间冲击、贴地动作、巨大体量、高速穿梭 |
| 28–35mm | 人物与环境关系、跟拍、动作连续镜头 |
| 40–65mm | 自然透视、双人关系、中景与胸像 |
| 75–135mm | 面部、微表情、过肩、焦点转移、压缩空间 |
| 200–300mm | 极强压缩、纯侧面动作、远距离窥视、极浅景深 |
| 微距 | 手、眼、嘴、道具、机械结构、接触瞬间 |

**长焦要尊重其视野。**200mm 水平胸像看不到大面积地面和天空。不要一边写 300mm 极浅景深，一边要求清楚展示完整场地。

**长焦与「隧道感／穿梭感」物理互斥。**速度感来自广角的边缘拉伸与灭点吸入，长焦压缩纵深、退行时景物只平移出画。

### 2. 景深写结果不写参数

「焦点锁定双眼，背景被压缩成柔和色块」优于只写「长焦」。焦点转移每镜只做一次，明确起点与终点。

### 3. 每次运镜写清起点、路径、速度、方向、结束构图

运镜必须由人物动作、信息揭示、情绪变化或空间关系驱动。一个镜头通常只用一个主运镜，可搭一个相容的副运镜。

### 4. 只给落点，不给路径

**先问：这条镜头的内容是不是方向本身？**

- **是**（退拍要揭示感、垂直穿越楼板、拉镜头终点要最开阔）→ 方向物证整套照用
- **不是**（内容是揭示的顺序、是画面里发生了什么）→ **一个方向词都不要写**，改成落点表

**落点表写法：**「依次到达下面几个落点，顺序不能变；每两个落点之间是连着的一段移动，具体怎么走不作要求，只要是同一台机器一路挪过去的，中间没有换过位置、没有断过；到了落点也不要停，画面还在动，只是这一刻画幅里是下面写的样子。」每个落点只写三样：画幅里有什么／这一档的景别与焦段／这一刻正在发生哪句台词。

释放路径之后仍要保留的硬约束只有两条，因为它们是性质不是路径：**全程不断**、**到落点也不停**。

### 5. 方向类镜头的物证

方向词能被读反，尺寸变化和进出边缘读不反。需要写方向时：

- **拉镜头**：「画面里任何一样东西，一旦出现就只会越变越小，一次也没有变大过。」（标量单调性，没有方向词可以翻反）
- **上升**：画幅里的一切往下沉、从下缘退出去，更高处的东西从上缘降进来（下降镜像）
- **差速视差**：最近处缩小得比深处快得多——这同时证明是机身位移而不是变焦
- **连续揭示台账**：每退一段画幅里就多一层，出现过的东西一样也没消失。**拉镜头是靠「不断有新东西从画幅四边挤进来」维持的，不是靠「往后退」这个指令维持的。**

### 6. 谁当主语，谁就动

画幅里某样东西位置变化的原因，必须写在真正在动的那个东西身上。

- 错：「从画幅下缘进来几条小腿」（主语是腿，模型让腿自己往上冒）
- 对：「机身朝画幅左边平移，本来在画幅外面的一块地面被移进画幅，画幅下缘那一条现在被几条小腿占住；它们相对地面从头到尾一寸没动过。」

### 7. 单镜到底

所有变化通过摄影机路径、走位、遮挡、焦点转移和匹配动作完成。**恒速是最强的防切镜口径**——「速度一个样，不快也不慢，一次也没有变过速、没有停顿过」。但恒速只锁了「不变」，没锁「多快」，速度量级要另写。

## 十三、影视质感

**抗 CG 的总判据：不是告诉模型「这是实拍」，而是不给它需要渲染的东西——砍掉画面里「被照亮且清晰」的表面积。**

### 1. 可用的通用质感描述

> 「真人电影摄影质感，自然肤色，受控反差，柔和高光滚降，暗部保留纹理，色彩分离清晰，人物与环境的色温、色相、亮度和曝光完全一致，轻微细腻胶片颗粒，无细节堆砌，无虚假 HDR 感。」

### 2. 不要用材质品质词

汗、油光、水润、反光这类词会触发 CG 与美妆广告的训练数据。改用胶片型号、纪实质感、结构性瑕疵。

### 3. 光比与暗部

高光柔和滚降不过曝成死白；暗部有层次不压成纯黑；**最暗的地方不是纯黑，还看得出一点点起伏。**

### 4. 实体特效优先

要压 3D 感，主锁是**实体特效定义**：现场实体生物服装而不是数字渲染、机械特效级别的假体。塑料玩具感靠**生产痕迹**立（分模线、缩痕、顶针印、浇口余料），不靠「光滑」。

### 5. 视效产生的光必须真实影响环境

照亮附近的皮肤、武器、雨滴、地面、烟尘、墙面，并随距离自然衰减。

### 6. 尺度用画面内的比例关系锚，不用绝对数字

- 差：「它有三米高」
- 好：「它的高度不超过太阳盘直径的一半」「它的肩膀比旁边那些羊的整个身子还高」「有一张人脸那么大，得用两只手才捧得住」

**画面内两样东西的比例关系读不反，绝对数字读得反。**

## 十四、分组情绪总控与现场声

### 1. 每组一段情绪总控

内容包含：**主情绪定义＋温度与节奏＋一句反面排除。**一组只押一个主情绪，情绪转折处优先拆成两组。

> 「本组整体情绪：压抑中的慌乱——呼吸急促，动作快而不稳，雨水和远处的爆炸声让人始终紧绷；是咬着牙的逃，不是崩溃大哭。」

### 2. 逐镜现场声

每镜末尾一句「现场声：」。**只写剧情现场真实存在的声源，绝不写 BGM 或「紧张的配乐响起」。**

四层里每镜只挑一到三种：环境底声／动作声／机械与城市声／人声现场感（喘息、哽咽、压低的嗓音；台词另行标注）。

**声音也有连续性**：贯穿性声源在连续镜头中持续存在，只随距离与遮挡变化；爆炸后有耳鸣式衰减，枪声后有余响，按物理过程演化，不得每镜重置。

### 3. 一镜到底条的声音要单独处理

**音效插在段落之间等于在正文里画了拍界线。**一镜到底的长条里，正文一行音效也不留，全部撤到顶部写成一条连着响下来的声音线（「底下一直垫着…；他起身那一下是…；接着是…；最后是…」）。

## 十五、人物表演

### 1. 情绪要精确，不能用相近但错误的情绪替代

犹豫不是害怕；茫然不是迟钝；克制的愤怒不是吼叫。情绪变化写成连续过程，避免同一镜塞入互相冲突的情绪。

### 2. 内敛不是动作小，是做出来之后不收回去

- 浮夸版：眉一挑、嘴一张、然后收回来
- 内敛版：**轻轻抬起来，然后就那么挂着，忘了收**

可执行写法：「他的嘴唇分开了一条缝，分开之后一直没有合上。他的眉毛往上抬了一点点，抬起来之后就那么挂着，一直没有落下来。」并补一句总述：「这几样动作都很小，做出来之后一直保持着，没有一样是先做大再收回去的。」

### 3. 动作数量本身就是刻意的来源

三秒里堆七八个面部动作，堆得多本身就是在演。**砍到只剩一两件，其余明写「脸上什么也没有多出来」。**

真正的情绪由一件事承担就够——比如「他忘了自己脖子上还有刀」，比任何表情都准。

### 4. 群体动作不许同时

多人同时的动作写成「极短时间里一个接一个、前后差不到两三帧」，并给每个人指派不同的动作。观感仍是齐的，但不会跑成机械同步。

### 5. 表演要绑在具体的字上

台词自带的比喻直接做成动作。动作要有准备、发力、接触、反馈、收势。

### 6. 复合动作不许写成完成态

凡出现「举到／抬到／摆成／握成」这类到位词，必须拆成至少三步按序写出，并给关键姿势一个明写的顿点（「停住不动」）。大动作没有可读的关键姿势就会糊。

## 十六、Seedance 2.5 撰写纪律

### 1. 可观测性是最高判据

**每个动词都要能换算成：画幅里什么在变大／变小／从哪条边进入／从哪条边离开／什么变清楚了／什么变模糊了／什么亮了／什么暗了。答得上来就留，答不上来就是修辞，换成那个可观测事实本身。**

常见的对照：

| 修辞 | 换成 |
|---|---|
| 退开／推近 | 任何东西一旦出现只会越变越小／越变越大 |
| 沉下去／升上来 | 画幅里的东西朝上走、从上缘退出去（降） |
| 爬上她的身子 | 机位从她的脚那么高升到她的脸那么高，中间经过裙子、腰带、头发 |
| 挪开一点／高出一大截 | 给量（约是她的头的两三个宽度） |
| 光把毛烧成亮线 | 每一根毛的边上亮出一条细线 |
| 焦点吃实 | 画面先虚一下，过半秒才清楚 |
| 长大 | 因为它离镜头更近，在画幅里占的面积增加 |

**唯一允许保留修辞的地方是纯音频描述**（「声音从喉咙深处磨出来」），它没有对应的画幅变化可换算。

**验收判据：改完必须更短或持平。变长了说明只是把文学词换成了技术黑话。**

### 2. 细节预算是固定的

**只要结果，不要描述具体细致的过程。**单条算力有限，写满细节等于把预算切碎。

- 看画面里有几个主体：一张脸的特写，预算全花在表演上；几十个人的混乱街景照搬同样密度就是切碎
- 写结果：「一条正在被砸开的街，人在拼命逃，兵在里头到处扑」，而不是逐个交代谁掀翻了哪个摊子
- 每段只保一个焦点事件，其余交给氛围
- **该留的只有模型推不出来的硬约束**：运镜与速度、视差判据、首帧承接、光比方向、负向词

### 3. 速度靠计数，不靠形容词

「快速」「急促」模型接不住。五件可计数的物证，每镜至少占三件：

1. **近处的枝条或蕨叶从画幅最前面刷过去，每半秒一次，遮掉画幅一部分再让开**（纵深奔跑镜头里最强的单一速度证据）
2. 飞出画幅的东西全部带横拖影，越靠边拖越长
3. 树干／物体从两缘飞出的数量，给每秒几根
4. 步频给每秒几步，机身跟着每步颠一次
5. 声音一层压一层，中间没有空档

**紧张感挂在距离上**：追兵的声音「一次比一次近，没有一次变远过」。两处留白要做成递进而不是重复。

### 4. 纵深冲刺不是侧面横拍

**横拍读出来是平移，纵深追拍读出来是冲刺。**纵深写法：画幅深处那个点在一角，所有物体从那个点朝四条边扩张出去，主体的一部分锁在画幅一角一分不动，**每蹬一次画幅深处那个点近一截**。

### 5. 极特写的运动状态只能靠背景

极特写里主体填满画幅、又是锁死跟拍，主体自身的位移在画幅里等于零。**运动状态的唯一载体是背景。极特写不写背景，等于宣布这个镜头是静止的。**

三样物证缺一不可：

1. 画幅边角上露出来的背景被拉成横向的一条一条，一直朝一侧流过去
2. 主体随每次落地上下颠一次，给每秒次数，机身跟着一起颠
3. **从主体身上震下来或被扬起来的碎屑一律不垂直落下，全部朝画幅后方斜着甩出去，角度全程不变**

第三条最赖不掉：**静止时掉落物必须垂直，只要它斜着走，画面就不可能是停的。**

### 6. 物理写法

- **刹不住的唯一硬物证是身体上下两截不同步**：「脚那一头已经慢下来，身子那一头还在往前，整个朝前倾过去，倾到脚撑不住。」光写「来不及刹停」模型只会给一个匀速撞。
- **急转弯**：「前半截已经朝右、后半截还在朝原方向滑，两截错开一段之后才对齐。」
- **撞晕／昏沉的可观测形式是反应变慢、幅度先小后大、节奏不齐**：弹回一小段→有支撑肢一时没撑住、歪下去一截、**停了一下**才撑回来→转三下，第一下慢而小、隔半秒才有第二下。**整齐的甩头等于没晕。**
- **腾空的硬证据是它底部和地面之间露出一条亮的缝**（缝从没有到最宽再回到没有）。高度是量词，剪影上读不出来。配套：提前起跳、做三次且间隔一样长、给一次遮挡物证、给落地物证。**落地的证据比腾空的证据好读。**
- **重量靠它压到的东西读**：草被压下去、松开弹回一部分；膝盖压进草里、草从两边分开。

### 7. POV 防御

**三条高危句式**（都会把镜头变成第一人称）：

- 「两只手从画面下边伸上来」
- 「画面里是他的两只手、那只螃蟹、和那口井」（清单里漏掉了人本身）
- 「镜头升到井口正上方朝下看」

**不带所属的方位词是 POV 的温床**：「头顶传来」「身前」「脚下」缺所属时，模型会默认那是镜头的。每个方位词都要带所属，或直接换成实体。

**要写「操作者在做什么」的物证时，把主语从人换成画幅**：「画幅一顿一顿地颠着，颠的节奏是一步接一步的、有轻有重」——节奏还是脚步的节奏，可画幅里没有任何属于镜头那一侧的身体。

**手入画的安全三件套**：手连着一条完整的手臂、手臂一路伸出画幅、末端连在画幅外那个人身上／明写从哪个方向伸进来并绑到画面里已有的事实上／明写镜头不是任何人的眼睛。

### 8. 负向词纪律

- **纯词组表，不是文档。**一个词一个概念，不带语境、不带否定、不带解释。
- **人物行为、时序、状态类的担忧一律在正文里正向写，绝不进负向表。**
- **交付前必查正负打架**：把负向词逐条在正文里做子串搜索，命中即改正文为正向说法。两种形态都要查——负向词在正文里被正向要求（负向「定镜」vs 正文「架在原处」）；正文用否定句点了负向词的名（正文「没有任何剪辑点」vs 负向「剪辑点」，等于同一个词喂两遍且正文那遍是双重否定）。

## 十七、诊断表：跑出来不对时怎么定位

| 症状 | 先查这里 |
|---|---|
| 全是切镜 | 事件密度太高（一条里超过十几个事件）／音效插在段落之间／每段起手句都在重报镜头状态／有快速甩动或速度切换 |
| 镜头没动起来 | 写了「逐段加快」（分段变速＝多个剪辑点）／用了否定式防御（「不减速」被读成匀速） |
| 景别不对、跑得更近了 | 正文里写了只有近景才看得见的细节（睫毛、毛孔、手背），细节描述本身在下景别的单 |
| 主体总是居中 | 只写了「压在一侧」而另一侧是空的／写了「占画幅一大半」 |
| 光太假太硬 | 遮挡物的粗细与距地距离没算／给光本身写了颜色 |
| 人物比参考图老 | 用了成熟气质词（沉稳、克制、从容）／侧光太硬把纹路刻出来了／没有显式排除衰老标记 |
| 姿势拘谨 | 双臂贴身垂放／姿态对称／手上没有正在做的事 |
| 表演太浮夸 | 动作数量太多／动作做了又收回去 |
| 某个元素一动不动 | 关键帧生成模式下没写它怎么动。**画面里每一样东西都要派活。** |
| 动作物理上做不到 | 先算距离与姿态，多半是设定本身无解，不是模型执行错 |
| 数量失控（人越来越多） | 用了「一层比一层」这类可无限延伸的阵列描述／只靠负向词排除 |

## 十八、输出前自检

### 空间与体态
- 真实位置、座位、朝向、距离是否继承？屏幕左右是否被误当成世界位置？
- 是否越轴，若越轴是否有可见理由或已向模型解释？
- 每镜是否写明起点体态且与上一镜结束体态一致？是否写明结束体态？
- 躺坐跪站倒地腾空之间的变化是否有镜头内可见的过渡动作？
- 伤势、血迹、湿透、破损一旦出现是否持续保留？

### 景别与构图
- 整组的景别序列是否有相邻接续？若有，是否是主体切换？
- 越肩镜是否按最近处主体算了景别？
- 每镜主体是否偏心？另一侧是否有实体占位？偏置方向是否与上一镜相反？
- 是否出现「占画幅一大半」这类与非居中互斥的写法？

### 光影
- 每镜是否都有光影描述？
- 光是否在动？运动是否挂在别的东西的运动上？
- 遮挡物的粗细与距地距离是否算过？
- 逆光条里每一处「亮」是否都能指出它长在哪条外轮廓线上？

### 质感与表演
- 是否有材质品质词（汗、油光、水润）？
- 尺度是否用了画面内的比例关系而不是绝对数字？
- 情绪是否精确？动作数量是否过多？是否有「做大再收回」的动作？
- 群体动作是否写成了不同时？

### 用词
- 每个动词是否都能换算成可观测事实？
- 方位词是否都带所属？是否有 POV 高危句式？
- 主语是否选对（谁在动谁当主语）？
- 负向词是否与正文打架（两种形态都查）？

### 声音
- 每镜是否有现场声？是否误写了 BGM 或不存在的声源？
- 贯穿声源是否连续、只随距离与遮挡变化？
- 一镜到底条的音效是否已撤到顶部、正文里一行不留？

**发现问题时先修复连续性与物理，再优化漂亮程度。**
