# 人物设定卡（Drama Characters）

## 前置

`drama_get_project` 读回契约与大纲——角色要服务于已排的事件，不要凭空加人。

## 每张卡必须回答

| 字段 | 要求 |
|---|---|
| 姓名 | 2~4 字，易读易记，避免同音混淆 |
| 身份定位 | 主角 / 反派 / 配角 / 龙套，一部剧主角不超过 2 人 |
| 性格关键词 | 3~5 个词，要有冲突感（如「冷静」＋「护短」） |
| 小传 | 3 句话内：出身、伤口、当前欲望 |
| 形象提示词 | **固定外形锚点**：年龄段、发型、服装主色、标志物。跨集复用，不要每集换衣 |
| 音色 | 一句话描述音色与语速 |

## 一致性纪律

1. 形象提示词一旦定下，后续所有分镜的生图提示词都要复用同一份锚点，不得改写。
2. 角色数量控制在 6 人以内；龙套不建卡，直接在剧本里写「路人甲」。
3. 说话人姓名必须与卡上姓名**逐字一致**，否则一致性检查会报 unknown-speaker。

## 交付

`drama_save_draft`（`kind: "characters"`，`content` 为角色数组的 JSON 字符串）写入草稿区。
