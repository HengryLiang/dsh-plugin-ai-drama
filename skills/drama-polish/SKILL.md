# 台词润色（Drama Polish）

## 红线

**只动台词，不动剧情。** 不增加事件、不改变人物关系、不提前泄露后续反转。
用户没说范围时，先问清要润色哪一集、哪几场。

## 润色判据

| 毛病 | 改法 |
|---|---|
| 台词太长 | 拆成两句，或删掉解释性内容 |
| 书面语 | 换成口语；读出来不像人说的话就是错的 |
| 信息直给 | 用动作或反问替代陈述 |
| 角色同质 | 按人物卡的性格关键词区分语气：冷静的短句、暴戾的脏字、油滑的拖音 |
| 无潜台词 | 让角色说的和想的相反 |

## 交付

修改后的完整剧本用 `drama_save_draft`（`kind: "episode"`）写草稿区，
并在回复里用**对照表**给出改动点：`原句 → 改后 → 为什么`。不要只丢一份新稿。
