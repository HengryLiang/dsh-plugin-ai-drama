# Seedance 2.5 生成用脚本 skill（Drama Seedance Prompt）

> 定位：把剧情改写成可直接投喂 Seedance 2.5 的**组控+逐镜 NL 脚本提示词**（本技能自有输出规范与自检；Seedance 生成用例的并列候选之一）；不接收其他脚本 skill 的产物做转换/补全。目标不是把文字平均拆开，是找到剧情的视觉节拍：建立关系、推进动作、强调转折、保留反应、完成落点。
> 边界：分镜表结构与镜号归 drama-storyboard；资产卡与参考图职责归 drama-asset；剧本写作归 drama-script。本技能只管提示词怎么写才能被模型正确执行。
> **与 drama-shot-prompt 的分工**：本技能＝Seedance 2.5 的分镜表达（每组情绪总控＋每镜自然语言段＋诊断）；drama-shot-prompt＝兜底六段模板与可拍性检查（面板复制口径）。同一批分镜不混用两种格式。
> **脚本 skill 选择（统一口径）**：脚本类为**多候选**，同一份脚本提示词由用户选定的一个 skill 端到端产出；本技能为 Seedance 生成用例，不与其他脚本 skill 串联/转换。当前 active 不是本技能时，先提示用户改选/切换，不静默代做；无合适 skill 时请用户选择，不默认套用。

**视觉圣经前置**：写提示词前调用 `drama_get_project` 读 `styleDNA`/`styleDirection`/`stylePrompt`；已冻结→五维为硬约束、保留并服从只读「视觉风格基准」章节；未冻结→先建/锁；不得私改风格。

## 1. 何时用

- 用户要「拆分镜 / 写 Seedance NL 脚本提示词 / 视频提示词 / 可拍性优化」；要其他格式/其他脚本 skill 时先让用户选择；
- 已有分镜表或剧本，要写成给视频模型看的自然语言段；
- 生成结果不对，要定位是描述问题还是模型问题。

## 2. 优先级（冲突时前项高于后项）

用户本轮最新修改 > 用户已确认要保留的内容 > 物理与几何可能性 > 空间/体态/道具连续性 > 参考图职责 > 剧情因果与情绪节奏 > 景别与非居中构图 > 光影与质感 > 焦段景深运镜 > 视效与声音。
「只改这镜」只输出该镜；「完整给我」输出全组并保留全部已确认内容，修新问题不能丢旧要求。

## 3. 主动引导（写之前）

- 没有分镜思路：先复述理解（3–5 句：发生了什么/谁在推动/情绪从哪到哪），再给 2–3 个**真实不同**的方向（克制长镜 vs 碎切紧张、跟施压方 vs 跟承受方、先全貌 vs 先局部、落点给动作 vs 给反应），至少一个反直觉并说明风险；不要直接开写。
- 前提不成立先反问：几何不成立（够不着）、姿态推不出机位、信息量装不下、角色能力与动作矛盾——先改设定，不闷头执行。
- 跑偏先定位：是描述的问题还是模型的问题，绝大多数是描述问题，按 §16 诊断表查。

## 4. 输出格式（默认）

- 每组一段【本组情绪总控】，全组共用；
- 每镜一段连贯自然语言，整合：焦段与景别／机位高度方位俯仰／主体在画幅中的位置与占比／前中后景／景深与焦点／运镜起点路径速度终点／人物起点体态、动作、视线、情绪变化与结束体态／环境反应与视效；
- **每镜必须有独立「光影：」句**，写光此刻怎么作用 + 这一镜时间里怎么运动；
- 每镜末尾「现场声：」，只写现场真实声源，绝无 BGM；
- 台词逐字保留、另行标注；
- 默认不写镜头时长、不写文学化标题、不拆字段表格——结构化语言会被读成分镜表，在一镜到底长条里尤其容易被当成切点。

## 5. 写前工作流

理解剧情 → 建参考职责表 → 建体态台账 → 提炼每组主情绪 → **先排完整组景别序列**（在写任何一镜之前）→ 再算镜头数与节奏（对话与情绪允许长镜和停顿；信息转折用反应镜或焦点转移；高燃动作方向明确、快切与速度变化；一镜到底只设计一条连续路径）。

## 6. 参考职责（一图一职责，不能串用）

| 参考 | 只负责 | 绝不带入 |
|---|---|---|
| 人物图 | 身份/面部/发型/年龄/体型/固有造型 | 姿势、机位、光、背景 |
| 服装图 | 服装结构、材质、配件 | 模特姿势与体型 |
| 场景图 | 空间结构、天气、时间、色调、材质 | 机位与构图 |
| 特效图 | 能量颜色、形态、密度、尺度 | 所在场景 |
| 关键帧 | 用户指定的机位、姿态、透视、构图 | 未指定部分 |
| 参考视频 | 动作连续性、上镜末帧、站位、速度、节奏 | 不当时装/场景母版 |

两条常犯错：**把身份参照当编辑母版**（姿势/角度/光/背景都要重新设计）；**有参考图就闭嘴**（参考图已有的不重复描述，否则诱导照搬构图）。但参考图给不了的必须写：**尺度**（「只有他一个手掌那么大」）与**场内关系**（「只到旁边那些人的腰那么高」）。

## 7. 空间连续性

- 世界坐标与画面左右分开记：反打可以让两人分别出现在不同画面侧，真实位置不变。
- 下一镜第一帧继承上一镜末帧：位置/朝向/视线、体态、手与武器、道具持有者与使用手、环境破坏与烟尘阶段、已进出画的人。
- 轴线：正反打默认同侧；换轴只能用镜内可见越过／中性镜头重建空间／人物可见转向／用户明确要求；反打左右互换不是跳轴，但要向模型解释「同一片空地另一头回拍」。
- 站位只写在看见它的那一镜，不做全局声明——全局块会渗进单人特写，模型会往画幅里塞人。
- 数量与排他靠空间封闭：正向数一遍（「就是四个」）+ 把身后位置占满（「他身后是空的地面和树干，再没有别的人」）；**不用负向词**（负向点名等于种进去）。
- 高风险处用一句正向连续性句重新锁定（「A 仍坐北侧，B 仍坐南侧，本镜只改变机位」），不要每镜机械重复。

## 8. 体态台账（动态承接）

每镜记录每人五项：体态（躺/趴/侧卧/坐/蹲/跪/站/跑/倒地/腾空/被控制）、朝向、手与道具、伤势与痕迹、接触与负重。

- 铁律：**下一镜开始状态 = 上一镜结束状态**；每镜必写起点与结束体态。
- 体态变化**不允许发生在切镜缝隙里**，只有三种合法：上一镜内完成／下一镜以原体态起幅并写出过渡动作／加过渡镜头。禁止躺着切坐着、跪着切站着、被撞倒切站好、空手切持物；任何机位变化都不能豁免。
- 群演与前台一旦明确动作，下一镜不得复位消失；爆炸/烟尘/火焰/积水按时间继续演化，不得重置。

生成提示词保留插件注入的「视觉风格基准」章节，不删不改。

## 9. 光影（每镜必写，最决定质感）

- 必写两件事：①此刻光落在哪、穿过什么、把什么照亮、把什么留在暗里；②这一镜的时间里光怎么运动——**没有任何一镜的光可以静止**。
- 光的运动挂在别的东西上：风推树冠→亮斑一块块移过、脚踩水洼→反光踩碎再复原、队伍不动是光从他们身上移过。
- 先算遮挡物：又厚又近（窗棂/栅栏）→硬边光柱；又细又远（树叶/藤蔓）→边缘化开的斑；遮挡物离地越近，光斑边缘越硬。写反=舞台射灯感。
- 光本身不带颜色：亮的是被照透的叶子，不是绿色光柱（否则出图变染色滤镜）。
- 大而低的遮挡本身是巨大柔光源：宽树冠下是整片柔和的暗＋零星不规则光斑。
- 逆光质量判据（覆盖以下维度，示例非穷尽）：亮线只长在外缘（逐点写死走向）、线以内整片压暗看不出五官、发饰只在朝光一侧亮几个小点。自检问句：描述里每一处「亮」都能指出长在哪条外轮廓线上，指不出来就是凭空加了一盏灯。
- 极亮背景上没有边缘光：主体压在太阳/天空上只能是纯黑一块，形状靠负形读（叉与叉之间的空隙亮）。
- 需要提高可读性时加背景亮度差，不要给主体补正面光（补正面光毁逆光）。

## 10. 景别接续与构图

- 景别阶梯：大特写—特写—近景—中景—全景—大全景。同一主体相邻两镜**不接相邻两级**（跳级或换主体）；唯一例外=视点主体切换（特写 A 接特写 B 成立）；越肩按最近处主体算；复合镜内靠距离连续变化不算切。
- 非居中是默认：每镜主体不放在画幅正中，偏置方向与上一镜相反；居中只用于仪式/审判/宣告/绝对权力/宿命对峙/正面威胁/时间静止/死亡/顿悟或用户要求。
- 不居中靠**实体占位**不靠留白：空着的一侧模型会把主体挪回中间；另一侧要有具体实体（虚焦肩背/暗形状）。
- 禁止「占画幅一大半」（与不居中互斥）；写成「占那一侧的三分之二，另三分之一归实体和背景」。
- 前景必须承担功能（是这个机位的定义），不要拿路人轮流走过填满规则；持续退拍的镜头里，能长时间留在最近处的只有跟镜头同向同速的东西；每镜只选一个主构图机制（压缩/对角线/框中框/前景遮挡/负空间/极端比例/反射）+ 最多一个辅助。
- 视觉路径四问：观众眼睛从哪进／前景或运动怎么引导／落点在哪／动作或视线从哪个方向离开并接到下一镜。

## 11. 焦段、景深、运镜

- 焦段与画面范围必须相容：18–24 空间冲击/贴地/巨大体量；28–35 人物与环境关系/跟拍/动作连续；40–65 自然透视/双人/中景胸像；75–135 面部/微表情/过肩/压缩空间；200–300 极强压缩/纯侧面/远距窥视/极浅景深；微距 手眼嘴道具/接触瞬间。长焦尊重视野（200mm 胸像看不到大地面）；长焦与隧道感/穿梭感物理互斥（速度感来自广角边缘拉伸与灭点）；微距只配特写/大特写。
- 景深写结果不写参数（「焦点锁双眼，背景压成柔和色块」优于只写「长焦」）；焦点转移每镜只做一次，明确起点与终点。
- 运镜写清起点、路径、速度、方向、结束构图；必须由人物动作/信息揭示/情绪变化/空间关系驱动；一镜通常一个主运镜 + 一个相容副运镜。
- **只给落点不给路径**：先问「这条镜头的内容是不是方向本身」——是（退拍揭示/垂直穿越/拉镜终点最开阔）才用方向物证；不是则一个方向词都不写，改落点表：依次到达几个落点、顺序不变、落点间是连续移动、到落点也不停；每落点只写三样「画幅里有什么／景别与焦段／此刻哪句台词」。硬约束只剩两条：全程不断、到落点也不停。
- 方向物证：拉镜=「任何东西一旦出现只变小不变大」；上升=画幅里的一切往下沉、从下缘退出；机身位移=差速视差（近处缩小比深处快得多）；揭示型拉镜=连续揭示台账（每退一段多一层，出现过的一样没消失）；单镜到底恒速=「速度一个样，一次没变过速」（还要另写速度量级）。
- 谁当主语谁就动：位置变化的原因写在真正在动的东西上（写「机身向左平移，画幅外地面被移进来」，不写「从画幅下缘进来几条小腿」）。

## 12. 影视质感（抗 CG）

总判据：不是喊「实拍」，是**砍掉画面里「被照亮且清晰」的表面积**。

- 通用质感句：真人电影摄影质感，自然肤色，受控反差，柔和高光滚降，暗部保留纹理，色彩分离清晰，人物与环境色温/色相/亮度/曝光完全一致，轻微细腻胶片颗粒，无细节堆砌，无虚假 HDR 感。
- 不用材质品质词（汗/油光/水润/反光会触发 CG 与美妆数据），改用胶片型号、纪实质感、结构性瑕疵。
- 高光柔和滚降不过曝；暗部有层次，**最暗的地方不是纯黑，还看得出一点起伏**。
- 压 3D 感：实体特效定义优先（现场实体生物服装/机械假体）；塑料玩具感靠生产痕迹（分模线/缩痕/顶针印/浇口余料）立，不靠「光滑」。
- 视效产生的光必须真实影响环境：照亮附近皮肤/武器/雨滴/地面/烟尘/墙面，并随距离自然衰减。
- 尺度用画面内比例锚，不用绝对数字（「不超过太阳盘直径的一半」「肩膀比旁边羊的整个身子还高」）；画面内比例读不反，绝对数字读得反。

## 13. 情绪总控与现场声

- 每组总控：主情绪定义 + 温度与节奏 + 一句反面排除（「压抑中的慌乱——呼吸急促、动作快而不稳；是咬着牙的逃，不是崩溃大哭」）；一组只押一个主情绪，情绪转折处优先拆两组。
- 现场声只写剧情现场真实声源，**绝不写 BGM/配乐**；四层里每镜挑 1–3 种：环境底声/动作声/机械与城市声/人声现场感（台词另标）。
- 声音有连续性：贯穿声源持续存在、只随距离与遮挡变化；爆炸后有耳鸣式衰减、枪声后有余响，按物理演化不重置。
- 一镜到底条：正文一行音效也不留，全部撤到顶部写成一条连着响下来的声音线（音效插在段落之间=画拍界线）。

## 14. 人物表演

- 情绪要精确：犹豫≠害怕、茫然≠迟钝、克制的愤怒≠吼叫；情绪变化写成连续过程，同一镜不塞冲突情绪。
- 内敛不是动作小，是**做出来之后不收回去**（「嘴唇分开一条缝，一直没合上；眉毛抬一点，抬起来就挂着没落下」），并补一句总述动作都很小且一直保持着。
- 动作数量本身就是刻意：三秒堆七八个面部动作就是「在演」；砍到一两件，其余明写「脸上什么也没有多出来」；真正的情绪由一件事承担就够（「他忘了脖子上还有刀」）。
- 群体动作不许同时：写成「极短时间里一个接一个、前后差不到两三帧」，并给每人不同动作。
- 表演绑在具体的字上：台词自带的比喻直接做成动作；动作要有准备、发力、接触、反馈、收势。
- 复合动作不写完成态：「举到/抬到/摆成/握成」必须拆至少三步按序写出，并给关键姿势一个「停住不动」的明写顿点。

## 15. Seedance 撰写纪律（最核心）

- **可观测性是最高判据**：每个动词都要能换算成——什么变大/变小、从哪条边进/出、什么变清楚/模糊、什么亮/暗。答得上来就留，答不上就是修辞，换成那个可观测事实本身。唯一允许保留修辞的是纯音频描述。**验收：改完必须更短或持平**，变长=只把文学词换成了技术黑话。
  常用换算：推近/退开→东西只变大/只变小；沉下去→画幅里东西朝上走、从上缘退出；挪开一点→给量（约她两三个头宽）；焦点吃实→画面先虚一下、过半秒才清楚；长大→因为离镜头更近、画幅占比增加。
- 细节预算固定：只要结果不要过程；看画面有几个主体分配预算（一张脸的特写全给表演）；每段只保一个焦点事件，其余交给氛围；该留的只有模型推不出来的硬约束（运镜与速度、视差判据、首帧承接、光比方向、负向词）。
- 速度靠计数不靠形容词（五件至少占三件）：近处枝条每半秒刷过画幅一次／飞出物全带横拖影越靠边越长／树干从两缘每秒几根／步频每秒几步机身跟着颠／声音一层压一层没空档。紧张感挂在距离上：追兵声音一次比一次近，没有一次变远。
- 纵深冲刺不是侧面横拍：画幅深处那个点在一角，所有物体从那个点朝四边扩张，主体一部分锁在画幅一角不动，每蹬一次深处那个点近一截。
- 极特写运动只能靠背景（主体位移≈0），三件缺一不可：边角背景被拉成横条朝一侧流／主体随落地上下颠（给每秒次数）／震下的碎屑不垂直落、全朝画幅后方斜甩且角度不变（静止时掉落物必须垂直，最赖不掉）。
- 物理写法：刹不住=身体上下两截不同步；急转=前半截已朝右后半截还在原方向滑；撞晕=反应变慢、幅度先小后大、节奏不齐（整齐甩头=没晕）；腾空=底部与地面露出一条亮缝（缝从无到最宽再回到无），落地证据比腾空好读；重量靠压到的东西读（草被压下、松开弹回）。
- POV 防御：高危类型（示例非穷尽）——「两只手从画面下边伸上来」／画面清单漏掉人本身／「镜头升到井口正上方朝下看」；不带所属的方位词是 POV 温床（「头顶传来/身前/脚下」必须带所属或换实体）；手入画的必要做法——手连完整手臂伸出画幅／明写从哪个方向伸入并绑定画内事实／明写镜头不是任何人的眼睛。
- 负向词纪律：纯词组表（一词一概念，不带语境/否定/解释）；行为、时序、状态类的担忧在正文正向写，绝不进负向表；交付前做**正负打架双向检查**——负向词逐条在正文子串搜索，以及正文是否用否定句点了负向词的名，两种都改成正向说法。

## 16. 诊断表（跑出来不对时先查这里）

| 症状 | 先查 |
|---|---|
| 全是切镜 | 事件密度太高（单条事件过多）／音效插在段落之间／每段起手句重报镜头状态／有快速甩动或速度切换 |
| 镜头没动起来 | 写了「逐段加快」（分段变速=多个剪辑点）／用了否定式防御（「不减速」被读成匀速） |
| 景别不对、跑得更近 | 正文写了只有近景才看得见的细节（睫毛/毛孔/手背），细节描述在下景别的单 |
| 主体总居中 | 只写「压在一侧」而另一侧空着／写了「占画幅一大半」 |
| 光假/太硬 | 遮挡物粗细与距地没算／给光写了颜色 |
| 人物比参考图老 | 用了成熟气质词（沉稳/克制/从容）／侧光太硬刻出纹路／没显式排除衰老标记 |
| 姿势拘谨 | 双臂贴身垂放／姿态对称／手上没有正在做的事 |
| 表演浮夸 | 动作数量太多／动作做了又收回去 |
| 某元素一动不动 | 没写它怎么动——画面里每一样东西都要派活 |
| 动作物理做不到 | 先算距离与姿态，多半是设定本身无解 |
| 数量失控（人越变越多） | 用了「一层比一层」式可无限延伸的阵列描述／只靠负向词排除 |

## 17. 交付前自检

- **空间体态**：真实位置/座位/朝向/距离是否继承？屏幕左右是否被误当世界位置？越轴有无可见理由？每镜起点体态=上镜结束且写明结束体态？躺坐跪站倒地腾空变化有镜内过渡？伤势/血迹/湿透/破损一旦出现持续保留？
- **景别构图**：整组景别序列有无相邻接续（是否主体切换）？越肩按最近处算？每镜主体偏心、另一侧有实体、偏置方向与上镜相反？有无「占画幅一大半」？
- **光影**：每镜都有光影句？光在动且挂在别物上？遮挡物粗细距地算过？逆光里每处「亮」都长在外轮廓线上？
- **质感表演**：有材质品质词吗？尺度用画内比例不用绝对数字？情绪精确、动作不过多、没有「做大再收回」？群体动作不同时？
- **用词**：每个动词能换算成可观测事实？方位词都带所属？有无 POV 高危句式？主语选对（谁在动谁当主语）？负向词与正文打架（两种形态都查）？
- **声音**：每镜有现场声？误写 BGM 或不存在的声源？贯穿声源连续？一镜到底的音效已撤到顶部？

发现问题时**先修连续性与物理，再优化漂亮程度**。
