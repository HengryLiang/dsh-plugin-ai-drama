# 视觉圣经（Drama Visual Bible）

> 定位：项目级**风格唯一真源**。风格只在这里定义一次；资产、剧本、分镜都引用它，不在下游私自改。
> 边界：不写 `.aidrama/style.json`（唯一写入口是面板「素材库 → 视觉圣经专区」）；不做图像生成/渲染；不代写资产卡与剧本；本技能负责「定风格 + 让下游服从」。

## 1. 何时用 / 不触发

- **触发**：用户说「视觉圣经 / 风格锁定 / 风格 DNA / Style Bible / 统一风格 / 风格漂移」；新建项目定视觉基调；已有资产或剧本风格不统一；审阅、改写、冻结视觉圣经；生成结果跑偏要定位风格问题。
- **不触发**：单张图生图、简单提示词优化（交 drama-asset / drama-seedance-prompt）；只问某张图好不好看（交 roundtable 或资产技能）。
- 用户没给任何参考或文字设定时，先要 3–10 张参考图或一段风格描述；**不要凭空编风格**。

## 2. 六维模型（插件事实，硬口径）

| 字段名 | 中文 | 必须写什么（量化优先） |
|---|---|---|
| `palette` | 色板 | 主/辅/强调色的 HEX 或色名+占比；色温倾向；饱和度策略；LUT/调色倾向；禁止色 |
| `lighting` | 光感 | 主光方向、色温 K、key:fill 光比、阴影态度（保留细节/压死）、rim light、practical 光源、体积光/眩光 |
| `texture` | 质感 | 材质光学（哑光/半哑光/镜面）、粗糙度、反射率、磨损/氧化/污渍、接触阴影；禁 CGI 塑料感 |
| `composition` | 构图偏好 | 画幅（9:16 / 16:9 / 2.39:1 等）、构图策略（非居中/负空间%/低角度…）、机位高度、前景使用、视线引导 |
| `motion` | 运镜节奏 | 镜头运动主导（固定/慢推/手持/环绕…）、人物动作风格、环境运动（风/雨/烟/粒子）、转场、节奏（快切/长镜） |

- 每维建议 1–2 句；**插件不设产品字数上限**，完整文本存 style.json（仅请求体 64KB 技术保护，不裁切）。
- **注入**：冻结后插件「视觉风格基准」章节总长上限 **4000 字**（六维顺序拼接，超出截断并标「…（摘录）」）；生成链 Prompt 预算仍 **2000 字**，超出的细节不保证被生成使用；完整文本仍存 style.json。
- 六维是**项目级**：不写单集剧情细节；一个项目一套光学系统（不混两个世界）。
- 保存时新客户端六维**必须六键全量提交**（空维用空串，至少 1 维非空）；旧五维客户端保存由宿主**保留现有 other**，不覆盖清空。
- **12 维 → 六维压缩**：Color / Shape / Pattern → palette；Lighting / Emotion（情绪光效）→ lighting；Material → texture；Composition / Lens / Architecture → composition；Motion → motion；不归 palette/lighting/texture/composition/motion 的风格要点 → other；Costume / Prop 落到资产卡（不进 bible）。


## 2.5 输入：风格分析与参考（v0.16.120）

- 当面板「视觉圣经 → 风格分析与参考」发起分析时，输入可能包括：
  - **参考图**：素材库已导入的 3–10 张图片（`素材/风格参考/`，assetId/路径；单文件≤50MB，逐张读取）；
  - **参考影片**：`referenceFilms`（≤20；title 1–120、year 字符串≤4（1888–2100 或空）、director≤80、note≤200）；
  - **参考导演风格**：`directorStyles`（≤10；director 1–80、note≤300）；
  - 当前六维 styleDNA / 状态（draft/directed/frozen）。
- **会话用户附图**：用户直接给图时，用 `drama_add_asset`（`attachmentId`+`importAs:'风格参考'`）导入「风格参考」；不自动写refs/分析；提示面板同步加入。
- **会话风格分析文件**：生成时用 `drama_write_content(kind=file)` 写 `构想/视觉圣经/风格草稿.json`（六维+other+films+directors+source{project,sessionId,analyzedAt,styleRevision}）；不写 style.json，面板可读取。
- **读图**：优先用 DSH `read_image` 读取参考图；逐张/分批读取，记录文件名与证据编号。无 `read_image`、纯文本模型路由、图片读取失败时：**明确降级**为仅基于文字参考/用户描述，不得编造视觉事实。
- **证据**：六维建议尽量引用参考图编号/影片/导演；冲突以图为准标矛盾；判断不了写待确认。
- **分析结果（建议态）**：六维建议（每维1–2句，不设上限；other可空）+ 参考要点（色板/光感/材质/构图/运镜）+ 风格锚点 + 矛盾点 + 置信度（高/中/低）+ 证据引用 + 限制说明；**不写 `.aidrama/style.json`**，由用户在面板确认/保存。
- **结果回传（必须）**：结果写固定路径 `构想/视觉圣经/风格分析.json`（用 `drama_write_content(kind=file, path=...)`，重跑覆盖同一路径）；JSON 含 kind/schemaVersion/analyzedAt/refs/films/directors/suggestions(六维 text+evidence+confidence；other 可选)/anchors/contradictions/limitations/model；可选 source{project,episode,styleRevision,styleHash,refsHash}；**不写style/不改其他文件/不生成媒体**；面板用 `doc-read` 读取并展示。

- **成本/边界**：一次分析=1次模型；不自动重试/后台；图片会发模型提供方、确认层已提示；不生成媒体/不改剧本资产卡。

## 3. 输出 A：六维 paste-ready（默认交付）

**分析请求的额外交付（若来自「风格分析与参考」）**：除六维正文外，附「参考图证据（编号/要点）」「参考影片/导演引用」「矛盾点」「置信度（高/中/低）」「限制说明」；不得写 style.json。

**写法纪律**
- 每条建议 1–2 句（不设产品字数上限）；数字优先（HEX / K / 光比 / % / mm），同一件事只写在一个维度（避免六维互相打架）。
- **从材料提炼四步**：①先图后文——图片是视觉事实（色/光/材质/构图），文字是意图；②冲突以图为准并标矛盾；③先定世界光学系统（高陡低 Key / 平缓中高 Key），再定 HEX 等衍生值；④每条落成可量化事实，落不成的写「待确认」。
- 禁空洞词：电影感 / 高级感 / 氛围感 / 质感好 / 震撼 / 唯美 / 有感觉。
- **不编造**：不能读图时让用户给 3–5 个 HEX 或色名+参考片，不虚构精确色值、镜头型号、参考作品履历。
- 参考图与文字冲突时**以图为准**并标「矛盾点」；判断不了写「待确认」。
- 每维先给一句「定位/理由」再给可粘贴正文（理由不进 style.json）。

**模板（逐维粘进视觉圣经专区）**

```text
palette（色板）：主色 #2A3A5C 冷钢蓝 60% + 辅色 #8B5A3C 锈橙 20% + 强调色 #D8DCE0 冷白 5%；低饱和、去饱和 LUT；禁霓虹/糖果色。
lighting（光感）：单侧侧逆光 3200K，key:fill 1:8；暗部保留纹理（-3EV 仍可见）；rim light 只勾金属边缘；室内必须有可见 practical，禁平光/无源光。
texture（质感）：哑光金属+旧化≥60%，反射率≤25%，可见划痕/氧化/积灰；接触阴影落地；禁镜面 chrome/CGI 塑料感。
composition（构图偏好）：竖屏 9:16；主体偏心、负空间≥50%；低角度仰拍 10–15°；前景遮挡做 dirty frame；视线引向画面深处。
motion（运镜节奏）：以固定/极缓推为主，手持仅冲突段；风与尘持续；转场用硬切或遮挡；节奏慢起、冲突段加速。
```

> 以上只示格式，实际按项目填；六维之间不许出现互斥参数（如同时「高饱和霓虹」与「低饱和禁霓虹」）。

**审阅现有视觉圣经**：按同口径逐维打回——字段名错、量化不足、出现空词、六维互相矛盾，任一命中就要求改；全过再进入锁定流程。

## 4. 输出 B：扩展视觉圣经（可选长文，不进 style.json）

用户要「完整版/可评审版/团队版」时，在六维之外另给 8 节（短表或短段，不写空话）：

1. **色彩剧本**：70% 基底/环境色 + 20% 动力光源色 + 10% 焦点情绪色；逐场景一张色卡（三层用色+来源 HEX/色温）；色彩节奏（开场→建立→转折→高潮→结尾）；禁止色；特殊色必须表现为色散物理，不做涂装色块。
2. **光影方案**：世界光学系统二选一或自定义（steep_lowkey 高陡低 Key / gentle_midkey 平缓中高 Key）；亮度阶梯（暗部下限%、高光上限%）；主光/K/key:fill/阴影/rim/practical；禁平光、禁无源光。
3. **镜头/焦段与构图**：焦段纪律（18–35 环境/冲击、40–65 关系/中景、75–135 面部/压缩、200+ 极压缩禁大空间、微距只配特写）；横竖画幅构图规则；机位高度=权力关系；构图策略+负空间%；景别接续留给分镜技能。
4. **材质质感**：每类主材写光学六维（漫反射/镜面/透射/折射/光泽）+ 粗糙度/反射率/磨损%；接触阴影；整体禁 CGI 塑料感、镜面 chrome、全新无痕。
5. **参考图墙职责**：每张锚点图只承担一个职责（锁色板/锁光感/锁质感/锁构图/锁运动）；写「不带入什么」（姿势/机位/背景/其他世界）；参考图是测量仪器不是生成母版；图与图冲突时以主锚点为准并标矛盾。
6. **负向/违禁清单**：三类——✅必须出现（Mandates，附验收标准）/ ⛔绝对禁止（Forbidden）/ 🎨软偏好（例外需叙事理由）；覆盖时代错误（塑料/电线/LED…）、禁材质、禁光型、禁构图、禁色；每条给 QA 维度。
7. **风格违禁词**：空泛质量词（电影感/高级感/氛围感/震撼/唯美）、通用画质词（masterpiece/best quality/cinematic/HDR/8K）、与圣经冲突的视觉元素词；负向词只做纯词组表，行为/时序/状态一律正写。
8. **QA 记分卡**：六维×20=120（风格契合/光影/材质/色彩/叙事）；≥80 通过，70–79 局部修，<70 回 DNA 层查；附 10 项快速自检（色板/主光/禁项/材质/构图/镜头签名/情绪/形状/时代/一眼可辨），≥8 项通过。

> 扩展版是参考文档，**不进 style.json**（style.json 只存六维）；落盘用 `drama_write_content(kind=file, path='构想/视觉圣经/<项目>.md')` 写入正式稿；写入失败时降级为**仅输出正文、不落盘**。

## 5. 锁定流程（P0，五步不跳）

**锁定/共享（v0.16.120 面板联动）**：锁定=保存当前六维+参考影片/导演文字到 `共享资料/视觉圣经/<名称>.json`（共享副本仅文字，**不含项目参考图/assetId**）+ 项目 freeze；共享写失败不冻结；解冻不删除共享副本；本技能不直接写共享文件/不写 style.json，流程由面板执行。


1. **读现状**：调用 `drama_get_project` 读取 `styleDNA`（六维原文）、`styleDirection`（status/revision/hash；旧项目无 state 视为 draft）、`stylePrompt`（仅 frozen 才返回固定章节）。若返回里没有这三个字段，**不许用其它接口猜、也不许脑补已冻结**，按 draft 处理并告知用户。先向用户复述现状。
2. **出六维**：按 §3 产出（若是面板「风格分析与参考」任务，先按 §2.5 读取参考图/文字参考并给证据化建议），附一句风格定位（流派/参考锚点/情绪基调）；让用户确认或改一版。扩展版（如需）按 §4 用 `drama_write_content(kind=file, path='构想/视觉圣经/<项目>.md')` 写入正式稿；失败则仅输出不落盘。
3. **保存风格 → 定向**：引导用户到「素材库 → 视觉圣经专区」逐维粘贴保存（唯一写入口是面板，Agent 不直接写 style.json）。定向要求至少 1 维非空；定向后微调保存需带当前 hash（面板自动处理；冲突先刷新状态）。
4. **冻结**：必须先定向才能冻结；冻结=硬锁，save/direct 一律拒绝（423 style-locked）。
5. **冻结后**：只读；要改必须先解冻并写原因（10–300 字）+ 当前 hash，回到 directed 并记入解冻历史（≤20 条）；每次成功写入 revision+1。

**状态语义（关键）**：draft / directed 只作参考，**不注入生成提示词、不保证一致**；只有 **frozen** 才注入固定「视觉风格基准」章节（≤4000 字，含六维非空项+只读说明），资产与视频生成提示词会自动带上——「真想锁死」必须走完冻结。
**若已 frozen**：先告警「只读，解冻需理由」，不绕过、不假装能改；用户坚持则引导解冻并记录。

## 6. 执行约束（下游必须服从）

**资产输出（drama-asset 建卡/提示词）**
- 卡内写「风格锚点」引用六维：palette/lighting/texture 为主，composition/motion 落到镜头层；
- 不新增与圣经冲突的材质/光型/色；参考图职责不与圣经冲突；生成提示词保留插件注入的 style 章节，不删不改。

**脚本输出（drama-script 场景/情绪/画面）**
- 场景描写、情绪、画面用六维约束（色彩节奏、光感、运镜节奏）；不写圣经禁止的视觉元素（如禁霓虹就不写霓虹灯牌）；
- 情绪→视觉按扩展版映射；分镜只引用，不重写风格。

**分镜提示词（drama-seedance-prompt / drama-shot-prompt）**
- 保留冻结 style 章节；镜头/焦段/构图服从 composition；负向词与圣经禁列对齐；不重复整套圣经。

**审计清单（交付前逐项勾，可打回）**
1) 资产卡锚点是否含色板/光感/质感？ 2) 剧本是否出现与圣经冲突的视觉元素？ 3) 生成提示词是否保留 style 章节（未被删改）？ 4) 新资产/新场景是否引用同一组六维？ 5) 是否有人在下游私改色板/光比/磨损度？ 6) 扩展版 QA 是否 ≥80？

## 7. 分工（防越界）

- **本技能** = 风格唯一真源：六维 + 扩展版 + 锁定流程 + 审计。
- **drama-asset** = 资产卡、参考图职责、资产门禁（执行圣经）。
- **drama-script** = 剧本文字、台词、结构（服从圣经描述）。
- **drama-seedance-prompt** = Seedance 分镜提示词（引用圣经，不重写）。
- **drama-shot-prompt** = 兜底六段/可拍性检查（保留 style 章节）。
- **roundtable** = 多评审会诊（可用来评圣经分析；不替代本技能）。
- 插件层：image/video 生成提示词的圣经注入已由插件自动完成（仅 frozen），本技能不重复实现注入。

## 8. 边界与异常

- **参考图太多/互相冲突**：先选 1–3 张主锚点，其余降为「质感参考」，标矛盾；冲突以图为准。
- **不能读图/纯文本模型**：明确告知「当前路由无法读图」，让用户给色名/HEX/参考片/一段文字；不编造，不把文字描述伪装成视觉分析。
- **文本过长**：插件不设产品上限；完整文本存 style.json；面板/Agent 注入摘录≤4000，生成链预算2000，细节可能不被生成使用；可移扩展版。
- **冻结章节被截断**：六维合计超 4000 字时注入章节会截断并标「…（摘录）」；生成链预算 2000 字更早截断；完整文本仍在 style.json，不要依赖截断兜底。
- **旧项目无 state**：读为 draft，不写回、不补默认；要走流程再定向/冻结。
- **风格漂移**：先看有无 stylePrompt（未 frozen=无注入，先冻结）；再按 QA 记分卡定位漂移类型（色彩/光影/材质/构图/风格/时代/叙事/光学），回对应维度改圣经，不在下游打补丁。
- **用户只想快速改一张图**：不触发本技能，交资产/分镜技能。
- **风格分析与参考**：面板发起分析时，参考图/影片/导演字段均由用户提供；本技能只输出建议，不写 style.json、不自动保存/定向/冻结。

## 9. 交付前自检

1. 六维字段名正确、六键全量（旧五维保存由宿主保留 other）？ 2. 量化足够（HEX/K/比例/%/mm）且无空词？ 3. 六维互不矛盾、不写单集剧情？ 4. 画幅与横竖构图规则写进 composition？ 5. 六维已让用户确认？ 6. 走完 draft→directed→frozen，或已明确告知「未冻结不保证一致」？ 7. frozen 后未尝试私改？ 8. 资产/剧本/分镜审计清单已勾？ 9. 扩展版（如需）8 节齐且未塞进 style.json？ 10. 与下游技能的分工说明已给？ 11. 分析任务是否引用参考图/影片/导演证据、标矛盾点/置信度？ 12. 是否确认没写 style.json、没伪造读图结果？13. 是否说明 4000 摘录/2000 生成预算？
