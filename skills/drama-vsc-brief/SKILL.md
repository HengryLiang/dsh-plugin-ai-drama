# 导演 VSC 简报（drama-vsc-brief v3.1）

> 仅当指令明确点名 `drama-vsc-brief` 或要求「生成 VSC 简报」时使用；针对当前 ShotKey。资产仅做只读引用。
> **VSC 简报 ≠ VCS**：VSC 简报是 shotKey 参考上下文；S1 VCS 由 `drama-script` 产出，本技能不产/不改分镜提示词。
> **数据前提提供者**：本技能是脚本 skill 的 VSC 简报来源（资产/风格/VSC 三前提之一）；只提供参考，不产/不改脚本提示词。

## 0. 职责边界（v0.16.224，用户口径）

- VSC 六区块 = **只给 Agent 使用脚本 skill 时的参考上下文**：资产引用/拍摄分析/镜头目的/情绪节拍/关键画面/构图建议。
- **不产出/不改写分镜提示词**；**不处理/不决定/不臆造镜头处理、景别、运镜、时长**；插件不再向 VSC 传镜头信息，分镜也不强制这些字段。
- 具体脚本提示词由脚本类所选 skill 端到端产出（不串联/不转换）；VSC 仅作参考输入，不能在 VSC 流程里产出提示词。

## 1. 输入（仅这些）
- 项目/集/**ShotKey**（`EP<集>-Shot<镜>`，如 `EP1-Shot2`）。
- **剧本原文摘录**（无则注明「无剧本摘录」）。
- **本镜已绑资产**（分镜资产区绑定的 `id+name`；无则「无」）。
- 既有 VSC（仅当前 ShotKey 数据用于更新）。

> **不再接收**：镜头信息（景别/运镜/时长）；全项目资产库清单；桌面/库级资产枚举。

## 2. 输出（按 ShotKey）
```json
{
  "shots": {
    "EP1-Shot2": {
      "assetRefs": [ { "id": "a-xxx", "name": "1.png" } ],
      "shootingAnalysis": { "time": "", "light": "", "props": [], "risk": "", "feasibility": "" },
      "shotPurposes": [ "" ],
      "emotionBeats": { "beat": "", "intensity": "", "note": "" },
      "keyFrames": "",
      "composition": ""
    }
  }
}
```
- `assetRefs`：**仅本镜已绑资产**（id+name）；**无则 `[]`（界面显示「无」）**。
- 六区块固定：**资产引用/拍摄分析/镜头目的/情绪节拍/关键画面/构图建议**。
- 资产引用不做规划/补充/缺失清单/库枚举。

## 3. 硬约束
1. **不得新增/绑定/修改/删除资产**；资产仅只读引用本镜已绑资产。
2. 不做资产规划/补充/建卡建议；无已绑资产→「无」。
3. 只写当前 ShotKey；不得写其它镜/集/分镜/视频提示词；不写其它文件。
4. **只输出六区块参考**；不产出/不改写分镜提示词；不处理/不决定/不臆造镜头处理、景别、运镜、时长。
5. 分镜不再强制镜头信息字段；VSC 不接收、不推断、不补默认；具体镜头设计与脚本提示词由所选脚本 skill 负责。
6. 写路径：`构想/导演剖析/<集>.analysis.json`（kind=analysis，add-only）。
7. 完成回一句摘要（≤1200 字）。

## 4. 指令模板（client 构建，固定顺序）
```
请使用 drama-vsc-brief skill 为当前分镜生成 VSC 导演简报六区块。
【技能】drama-vsc-brief（v3.1）
【ShotKey】EP1-Shot2
【项目/集】<项目名> · 第NNN集
【剧本原文摘录】<…；无则「无剧本摘录」>
【本镜已绑资产】<id：name；无则「无」>
【职责】六区块仅参考；不处理镜头信息；不产出/不改写提示词；镜头设计与脚本提示词归所选脚本 skill
【上限/写入】摘要≤1200字；写入 构想/导演剖析/第NNN集.analysis.json（kind=analysis，add-only）
【禁止】禁止新增/绑定/修改/删除资产；禁止改其它文件/分镜/视频提示词；不处理/不臆造景别·运镜·时长；不要输出 JSON；不要列资产库；完成后回一句摘要。
```

## 5. 禁止项
- 禁止出现「资产库清单」或全库枚举；禁止资产规划/补充/缺失/建卡。
- 禁止写资产库/其它镜/其它集；禁止输出 JSON（按 schema 字段写入 analysis 文件即可）。
- 禁止在 VSC 流程产出/改写分镜提示词；禁止处理/臆造镜头处理/景别/运镜/时长。
