# 分镜表（Drama Storyboard）

## 前置

`drama_read_episode` 取该集剧本；`drama_get_project` 取人物卡的**形象提示词锚点**。

## 每个镜头八列

| 列 | 要求 |
|---|---|
| 镜号 | `集-序`，如 `1-1`、`1-2`；集内连续，不重复 |
| 景别 | 可选；镜头信息由脚本提示词承载，插件不展示/不校验 |
| 运镜 | 可选；镜头信息由脚本提示词承载，插件不展示/不校验 |
| 画面描述 | 只写镜头里看得见的 |
| 台词 | 该镜头内的对白或旁白，可空 |
| 音效 | BGM / 环境音 / 拟音 |
| 时长 | 可选；由脚本提示词/项目节奏决定，插件不展示/不校验 |
| 提示词 | 生图提示词：**复用人物卡的形象锚点**＋本镜画面＋光线氛围 |

## 镜头信息非强制（v0.16.224，用户口径）

- **分镜不再强制提供景别/运镜/时长字段**；这些信息由脚本提示词承载，插件**不处理/不显示/不校验**。
- 不得默认填「中景/固定/3s」；未定可留空，不编造、不占位。
- 核心是**资产图 + 脚本提示词**；VSC 简报仅参考，不产出/不改写提示词。
- 不提供「重跑镜头设计」操作；不通过结构化字段改写镜头信息；旧数据字段保留兼容、不迁移/不删除。
- 脚本提示词由脚本类所选 skill 端到端产出；可选“生图/生视频提示词”字段仅作结构参考；本技能只做 S3 结构存储/渲染，不制定脚本格式、不生成/改写提示词。

## 节奏纪律（软约束，非硬门禁）

1. 开场尽早给钩子（冲突/悬念/强视觉）——具体秒数由项目契约与导演意图决定，**技能不设硬性秒刻度**。
2. 切镜频率服从段落节奏目标（分组总控 `rhythm`）与单集时长契约；长镜用于强调时写明目的。
3. 全集合计时长必须落在契约的单集时长区间内（`drama_check_consistency` 校验）。

## v0.16.40 P0 新流程（文本适配；工具调用/参数不变）

1. **集 → 场 → 段 → 镜**：顶部集下拉先定集；剧本页「分段」模式按场景/关键画面出段（建议 3–8 段/集，一段不跨场）；分镜页默认「流水线」模式按段推进。
2. **分组总控**：每组先写总控（情绪曲线/节奏目标/视觉基调/本组禁令），全文落分析 JSON `groupControls[groupId]`；`storyboard-groups.notes` 只作 ≤500 字短摘要，侧车不回写未知字段。
3. **卡片与复制**：单镜/整组/整段/整集复制默认六段（总控+镜头段/光影/现场声/台词/资产），空值固定占位；复制由面板纯函数生成，剪贴板与预览同源。
4. **命名**：卡片/表格/复制显示 `EP001-Shot-01`（旧自由镜号**只展示不改写**）；无映射的旧镜号保留原值并标「未标注/无法解析」。
5. **保存链**：面板保存=`storyboard-save`（写 JSON+MD+history 按现状）；Agent 产物=`drama_write_content(kind=storyboard)` 写入正式分镜（写前快照/expectedHash 保护）。

## 交付

`drama_write_content`（`kind: "storyboard"`，`order` 为集数，`content` 为镜头数组的 JSON 字符串）写入正式稿，
然后 `drama_check_consistency` 自检（重点看镜号重复与结构；镜头信息不再作插件校验项）。

## 写入稳健性（2026-10-20 补充）

- 镜头数组大时**分批提交**（每批建议 ≤10 镜），不要与人物/大纲等其他大参数并行写入。
- 写入分镜后若宿主报 `value.result must be an object`，那是输出校验误报（v0.15.8 已修），数据已落盘，**不要重复采纳**。
- 模型层报 `tool input is invalid JSON` 时先查审计/进度判断是否已落盘，未落盘再拆小重发。

## 快照限制（A-25/LIM-2，2026-10 已知）

当前版本 storyboard accept 的 history 快照为 no-op（见 `HOST-AUDIT.md §6.8`）；不要向用户承诺「可回滚到上一版分镜」，需要历史请手动复制分镜文件（P1 修复）。
