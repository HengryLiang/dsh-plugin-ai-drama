# 剧本创作（Drama Script）

> 定位：管剧本**写得好不好**——结构、人物、台词、可拍性。字段格式与落盘归各模块技能；本技能只负责剧本纪律与 **S1 VCS 交接口径**；最终脚本提示词由脚本类所选 skill 端到端产出（本技能不产提示词、不做格式裁决）。
> 本技能最终产物 = **VCS 镜头脚本（S1）**；脚本提示词由用户选定的一个脚本 skill（内置示例或创作者 skill）端到端产出，本技能不参与、不串联。
> **职责边界**：本技能归**剧本类（story）**，负责剧本创作纪律与 S1 VCS；最终脚本提示词由脚本类所选 skill 端到端产出（插件不串联）；本技能不产提示词、不做格式裁决。

**视觉圣经前置（强制）**：写剧本/视觉事件/情绪视觉化前，先调用 `drama_get_project` 读 `styleDNA`/`styleDirection`/`stylePrompt`；已冻结→场景色光、氛围与视觉修辞服从五维，不写与冻结值冲突的视觉设定；未冻结→先提示建/锁（视觉圣经技能），给下游留风格提示。

## 1. 何时用

- 用户给想法/小说/一句话，要写成短剧剧本；
- 剧本被评「平淡、拖、台词生硬、没有钩子、不像人话」；
- 要审一集剧本、诊断台词、检查反转是否立得住；
- 要写 VCS 镜头脚本，或剧本转分镜前做可拍性检查。

## 2. 创作流程（五步，按序，不跳）

1. **想法**：一句话说清「谁、想要什么、被什么挡住、失败会怎样」，并定平台/单集时长/画幅/受众。四样说不出来先问用户，不臆造。
2. **大纲**：每集六件事——标题（爽点/悬念式，不文学化）、一句话梗概、开场钩子、中段反转、结尾悬念、预计时长；集数连续不留缺口；钩子与反转不得跨集重复。
3. **人物**：主要角色必须有**欲望**（要什么）、**伤口**（怕什么/缺什么）、**手段**（能做什么）；**主角聚焦**（按集时长/叙事需要，不设硬上限）；龙套不建卡，直接写「路人甲」；说话人姓名与人物卡逐字一致。
4. **分集剧本**：以场次为单元，场景标题 `内景/外景 - 地点 - 时间`；单集 2–4 场，优先室内、少角色；只写镜头能拍到的。
5. **VCS 镜头脚本**：把剧本转成「导演监视器上看到的画面流」（见 §4），交脚本类所选 skill 端到端转写为脚本提示词（不指定格式）。

每步先给用户看、确认后再进下一步；不要一口气闷头写十集。用户要「先看方案」时，先给 2–3 个真实不同的方向（含至少一个反直觉+风险），不要直接开写。

## 3. 结构判据（可执行）

- **前 3 秒钩子**：悬念/反差/情绪/声明四选一，必须是一个可感知的视觉事件，不是气氛铺垫。
- **单集结构（1–3 分钟）**：钩子 10% / 铺垫 20% / 冲突升级 30%（至少 2–3 次升级）/ 高潮 25% / 结尾钩子 15%。
- **7 节拍**：钩子 5–8s → 建立 8–12s → 第一冲突 8–12s → 升级 8–12s → 高潮 10–15s → 余韵 5–10s → 结尾钩子 5–8s。
- **反转必须伏笔对账**：打脸/逆袭所依据的钩，必须在本集或前集显式埋下，并在反转场逐字回收；空降反转=编剧作弊；反转后必须给「代价或余波」一拍（对方眼神/第三者反应/新冲突种子）。
- **每集结尾**必须留一个逼下一集的问题（新危机/新秘密/反转）。
- 大纲只排事件与情绪曲线，不写台词；单集总时长必须落在契约区间内。

## 4. VCS 镜头脚本七铁律（写完逐条自检）

A **事件先行**：第一句是「画面里发生了什么」，不是「这是什么环境/有什么参数」。
B **动词驱动**：每拍至少一个主动词；不用「是/有/位于/出现」，用「轰然/滑出/落到/推近/扬起/炸开/吞没」。
C **镜头是角色**：镜头用主动语态（「镜头落到/缓缓推近/同步后退/俯冲贴近/猛地拉开」），不用「固定镜头/微震」等状态词；`硬切。` 单独成行=剪辑点。
D **光影写画面印象**：写「冷青尾焰把碎片边缘勾亮」「仪表蓝绿光映亮下颌」，不写「8000K rim light」这类参数与光型术语。
E **参数不进正文**：焦段/光圈/色温/景别/运镜只作括号补充或下沉到分镜提示词。**括号删除测试**：删掉所有参数，导演仍能在脑中完整播放这几秒，才算合格 VCS。
F **声音嵌入画面**：声音紧贴触发它的动作（「伴随轰隆闷响」「『铛——』一声金属闷响」），不单列音频字段。
G **排版即节奏**：短句换行=快，长句流畅=慢；`硬切。` 单独成行；单字行（「忽然。」「猛地。」）制造断点；空行=呼吸。

结构：每镜 = 开场画面（2–4 句）→ 事件发生（1–3 拍）→ 镜头反应（1–3 句）→ 结束画面（1 句，明确收尾）。每镜开头写目的三行：**镜头目的 / 不可删减要素 / 本镜不是什么**；末尾附节拍时间预算（节拍/时长/弹性，标出哪拍不可压缩）。

**每镜先答七问**（答不出就不该有这个镜头）：这一镜讲什么？观众此刻该感受到什么？谁是画面主角？观众先看哪里？观众此刻应该知道多少？为什么现在切镜？为什么用这个景别/运镜？
**心法（质量原则，不按条数验收）**：机位高低就是权力关系，焦段长短就是心理距离；运镜必须有理由，静止是奢侈品不是失败；光是电影的气质，无源之光是廉价感的根源；跳轴必须是「我故意的」；所有技法都是手段，唯一标准是观众这一秒的情绪比上一秒更强。
**信息控制**：不提前告诉观众答案；重大发现先拍反应再揭示；观众知道的和角色知道的按设计推进。

## 5. 台词与表演

- **台词是动作**：前置动作 → 停顿 → 情绪 → 短句 → 反应；禁止裸台词，禁止「口型微动做说话状」。
- **长度**：陈述 ≤12 字、爆发 2–6 字、金句 ≤20 字；一句台词一个情绪；长台词一口气说完、配专属反应镜与语气描述（拆的是文字，不是拍点）。
- **停顿比台词重要**：重要台词前有决策停顿 0.5–1.5s；金句后留白 0.5–2s。
- **辨识度**：遮住角色名必须能听出谁在说话——按人物卡给语速、用词、口头禅。
- **每句必须让张力前进**：连续 3 句没有推进就删；不写解释剧情的废话、不写功能性寒暄。
- **零抽象表演**：禁「难过/愤怒/表情复杂」，写眉/眼/嘴/颌/鼻＋精确动词；情绪转换=起幅→过渡（肌肉争夺 0.3–1s）→落幅；有人物就写呼吸；特写写面部五区，全景不写微表情。
- **表演量表（0–5）**：0 模特／1 朗读者／2 勤勉／3 工匠／4 活人／5 磁铁。交付标准 **≥4**（对白与情绪重场 ≥5）；用户明确要克制/风格化时除外，但须写明理由。对白镜要有 起幅→过渡→落幅 与 Voice 句（台词逐字），表演写进时间轴段与【声音】，不替代分镜结构。
- **次要角色分档**：背景板档只写位置/数量/服装色块；氛围层档写循环微动词（呼吸/重心/指尖），声明表演权重低于主体。

## 6. 小说/文本 → 剧本：不可见必须转可见

| 原文类型 | 转成 | 禁例 |
|---|---|---|
| 心理描写 | 表情+动作+台词+环境反馈 | 「他心中暗喜」 |
| 环境描写 | 关键视觉+光源+色温 | 「阴森恐怖的古堡」 |
| 长对话 | 拆 ≤15 字短句 | 30 字独白 |
| 动作描写 | 部位+动作+对象+结果 | 「拔剑向敌人砍去」 |
| 时间跳转 | 视觉过渡（春花→秋叶） | 「三年后」 |
| 回忆闪回 | 慎用，用表情/台词暗示 | 叠化闪回 |
| 内心独白 | 画外音或低声自语 ≤15 字 | 长段 OS |
| 背景设定 | 放人物卡/场景卡 | 剧本里讲世界观 |

## 7. 转分镜的交接口径（细节写法交给分镜技能）

> 统一口径：被引用能力需先切换当前启用技能（active）后使用；脚本类为**多候选**（同一份脚本提示词由所选一个 skill 端到端产出），未切换时按本节口径先出最小可执行版本。

- **一镜一事**：单镜时间窗内动作事件 ≤2；每镜先回答「观众必须看到的那一个信息」；镜内主动作 ≤3，超出拆镜。
- **可观测**：每个动词能换算成画面变化（变大变小/变亮变暗/从哪条边进出/清楚↔模糊）；换算不了就是修辞，删掉或改写；**改写后必须更短或持平**，变长=把文学词换成技术黑话。
- **镜头时长**：单镜 4–15s 为宜（Seedance 2.0 档；2.5 档可 4–30s，>15s 要用时间戳分镜语法）；分镜提示词正文默认不写时长。
- **景别接续**：同一主体相邻两镜不接相邻两级（要跳级或换主体）；越肩按最近处主体算；镜内景别变化只靠距离连续变化。
- **构图雷区**：不割颈/割腰、头顶不长物、非仪式不摆死中央、背景不抢焦、视线不撞墙。
- **体态承接**：下一镜起始体态=上一镜结束体态；变化不能发生在切镜缝隙，只能镜内完成/过渡镜/写明过程。
- **光影与现场声**：每镜独立光影句，光要动且挂在别物运动上；现场声只写画面内真实声源，绝不写 BGM。
- **负向词纪律**：负向词只做风格/品质/物理排除的纯词组表；行为、时序、状态的担忧一律正写（「不要出现更多人」会把人种进画面）。
- **生成指令层纯净化**：分镜提示词正文只写模型能执行的画面语言——禁字段标签行（「事件：」「光线：」）、禁 meta 语言（门禁/铁律编号/档位/豁免声明/拆拍）、禁生产腔；声明与纪律放文件头与关键限制。
- **镜头信息非强制（v0.16.224 用户口径）**：分镜**不再强制提供景别/运镜/时长字段**；镜头信息由脚本提示词/分镜提示词承载，插件不处理/不展示/不校验。不得默认填「中景/固定/3s」，未定不编造；旧字段保留兼容、不迁移。
- **提示词归属**：最终脚本提示词由脚本类所选 skill 端到端产出（同一份提示词不串联/不转换）；VSC 只作参考输入，本技能不产/不改提示词。
- **不要求重跑镜头设计**：不再提供「重跑镜头设计与结构化镜头字段」操作；只按用户当前创作需求产出脚本/提示词，不改结构化镜头字段。

## 8. 质量纪律

- **反捧杀**：禁止「整体精彩、瑕不掩瑜」类空话；问题严重直说（「前 3 秒钩子不及格」），改法落到具体句子，不写「建议优化节奏」。
- **不捏造**：不新增世界观/人物/设定（除非用户提供）；不虚构参考图/占位符/画幅/模型参数；缺信息先问，问不到就写「需确认」并说明缺什么。
- **回读确认**：立项、大纲、人物、每集剧本写完后，把关键设定（姓名、关系、画幅、时长、钩子）读回给用户确认；用户临时口述不当最终契约。
- **修改协议**：用户最新修改优先；已确认内容必须保留；「只改这镜/只改这段」只输出该段替换版，用户说「完整给我」才出全稿；已删除内容不得复活。
- **安全**：虚构世界观；无真实品牌/政治人物/未成年人风险内容；画质词 ≤2 个，删抽象形容词（beautiful/epic/stunning）。

## 9. 交付硬门禁（G0–G7 逐项 PASS，缺一返工）

| 门禁 | 本技能口径 |
|---|---|
| G0 S1 完整性 | VCS 齐、目的三行/七铁律/节拍预算齐全（脚本提示词由脚本类 skill 各自验收） |
| G1 构图 6 要素 | 每镜：机位／主体位置与占比／运镜／光线／表演／画内元素、画外元素，任一模糊即补写 |
| G2 四组件及格线 | 素材描述／一句话概述／具体情节描述（➕正向＋➖局部负面）／全局补充 |
| G3 表演量表 | 0–5 量表，交付 ≥4（见 §5） |
| G4 台词 | 与剧本逐字一致（含标点语气词）；长度、停顿、反应合规 |
| G5 关键限制 | 一级禁止 ≤5 项、二级禁止 ≤5 项、高风险逐条可执行；不堆通用负面词 |
| G6 连续性 | 每镜写明姿态/位置/轴线/天气/光线承接，无「场景相同」空话 |
| G7 时间轴 | 表头账本层首尾相接；正文不写 `00:0` 时段（2.5 档时间戳 profile 除外） |

另加创作纪律复核：前 3 秒钩子／结构七节拍／反转伏笔对账／一镜一事／可观测换算／反捧杀（问题直说、改法到句）／不捏造／已回读确认。

## 10. 禁止

- 跳过 VCS 直接写脚本提示词；
- 标签堆砌式 Prompt（masterpiece/best quality/ultra detailed/HDR/8K）；
- 用抽象形容词或情绪词代替画面；
- 在 VCS 正文写心理描写、角色外貌（外貌由资产/参考图控制）、BGM；
- 一个镜头塞多个主事件靠压缩时长硬塞。
