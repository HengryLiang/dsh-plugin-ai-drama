# 兜底分镜提示词写作（Drama Shot Prompt）

> **定位：兜底。** 默认写作路径是挂载的外部「草帽」分镜技能；当外部 skill 不可用（未挂载/路径失效）时，用本技能的判据保证仍能写出可执行的分镜提示词。**不复制草帽原文、不与其争写作方法**；外部技能可用时让位（优先用草帽）。
> 目标体积 8–12KB（≤12KB）。

## 1. 何时使用

- 用户要「分镜提示词 / 分镜图提示词 / 视频提示词 / 可拍性优化」时；
- 已有分镜表（项目隐藏目录下的分镜 JSON）需要补写成「给生成模型看」的自然语言段时；
- 需要检查一段分镜提示词「能不能被执行」时。

**不负责**：剧本、大纲、人物设定、资产卡（由各自技能负责）；本技能只处理**分镜层提示词的写作与自检**。

## 2. 输出格式（三件套）

### 2.1 全组情绪总控

先写本组总控：① **情绪曲线**（起→承→转→收，例如「压抑→警觉→爆发→余味」）；② **节奏目标**（总时长、平均单镜时长、哪几镜快/哪一镜慢）；③ **视觉基调**（色调/光比/质感，用可量化描述，不用「高级感」类空词）；④ **本组禁令**（本组绝不允许出现的东西，写具体）。

### 2.2 逐镜自然语言段

每个镜头写 4–8 句，顺序固定：① **主体与位置**（谁/什么、在画面哪个区域、占比）；② **动作过程**（起点→过程→终点，写方向与幅度）；③ **空间关系**（机位距离/高度/角度，前中后景各有什么）；④ **光**（光源/方向/强弱/是否在动/遮挡与反射）；⑤ **声**（画面内真实声源）；⑥ **镜头意图**（观众必须看到的那一个信息，一句话）。

### 2.3 结构化字段（与分镜 JSON 对齐）

| 字段 | 内容 | 要点 |
|---|---|---|
| shotNumber | 镜号 | 集内连续、不重复 |
| shotSize | 景别 | 固定枚举（大特写/特写/近景/中景/全景/大全景） |
| cameraMove | 运镜 | 从哪到哪、速度、是否稳定 |
| description | 画面描述 | 可拍的具体画面，不写抽象感受 |
| dialogue | 台词 | 与剧本一致；无台词留空 |
| sfx | 音效 | 画面内真实声源 |
| durationSec | 时长 | 单镜 4–15s 为宜 |
| emotion | 本镜情绪 | 情绪名 + 强度（如：警觉 70/100） |
| light | 光影句 | 光源/方向/强弱/运动/遮挡（见 §3.4） |
| ambientSound | 现场声 | 环境底噪 + 触发声（见 §3.5） |
| constraints | 本镜禁令 | 1–3 条，写具体 |
| poses | 起止姿态 | `{startPose, endPose}`（见 §3.3） |
| transitionToNext | 与下一镜衔接 | hard-cut / match-cut / whip-pan / one-take |
| naturalLanguagePrompt | 本镜自然语言段 | §2.2 的成段文本 |

> 字段为建议填充：v0.10 分镜 JSON 按 add-only 扩展；旧分镜只有基础字段时，先在 description/sfx 中承载，不虚构字段。

## 3. 八项写作纪律

### 3.1 可观测性换算（PD-01）

动作/状态词必须能换算成画面变量：**变大/变小、变亮/变暗、从画面哪条边进/出、清楚↔模糊、颜色/材质变化**。换算不了的词视为修辞，删掉或改写。

反例「气氛压抑到极点」「命运在此刻流转」（无法拍）；正例「他把杯子推过桌沿，杯底在桌面留下半圈水痕」。

### 3.2 景别接续（PD-02）

景别阶梯：**大特写 < 特写 < 近景 < 中景 < 全景 < 大全景**。同一主体相邻两镜**不要直接接相邻两级**（要跳级或换主体）；唯一例外是视点主体切换；越肩镜按最近处主体算；镜内景别变化不算切换。写完把 shotSize 序列拉出来逐对检查。

### 3.3 体态承接台账（PD-03）

每镜记录 **startPose/endPose**，至少覆盖：朝向、双手与道具、伤情/痕迹、负重/接触、身体高度。下一镜 startPose 必须等于上一镜 endPose；变化不得发生在切镜缝隙，只允许三种合法过渡：①过渡镜专门展示；②连续动作同镜完成；③文本写明变化过程。

### 3.4 每镜光影句（PD-04）

每镜独立光影描述：光源在哪、什么方向、强弱/色温倾向、亮暗怎么过渡；**光要动**，且运动挂在他物运动上（人走过、车灯扫过、云移、水面晃）；逆光只勾外缘亮线，极亮背景不写边缘光；颜色交给材料/介质表达；遮挡/反射/半透明要交代。

### 3.5 现场声（PD-05）

只写画面内真实声源：环境底噪、动作声、必要人声；**不写 BGM/配乐/背景音乐**；声音与动作/画面变化对齐（何时响、何时停）；跨镜连续；一镜到底时收成一条声音线。

### 3.6 正负表述纪律（PD-06）

负向词只用于「风格/品质/元素」排除表；**行为/时序/状态一律正写**（负面点名等于把它写进画面）。交付前双向检查：①正文出现了排除表负向词吗？②用否定句点名负向行为了吗？两处都改写或删除。

### 3.7 一镜一事（PD-08）

单镜时间窗内动作事件 ≤2，超过就拆镜；每镜先回答「观众必须看到的那一个信息」；一镜一主体焦点，不在一个镜头里争夺两个主角。

### 3.8 焦段纪律（PD-09）

广角（≤28mm）适合全景/大全景、空间关系，避免脸部特写；中焦（35–85mm）适合中景/近景/对话；长焦（≥135mm）适合特写/大特写与远距压缩，避免全景；微距只配特写/大特写。焦段与景别不许错配。

## 4. 正反例（自写短例）

**可观测性**：坏「他在门口犹豫了很久，气氛复杂」；好「他在门槛外停住，抬手又放下，脚尖朝门内挪半步又收回」。
**光影句**：坏「灯光很美，画面有电影感」；好「右侧窗户进光斜切过桌面；他起身时半张脸进亮区；窗外车灯扫过，墙上影子从右往左滑了一下」。
**一镜一事**：坏「他进门、脱外套、接电话、把旧照片收进抽屉」；好（拆三镜）「①进门；②挂外套；③拉开抽屉放旧照片」。
**正负表述**：坏「不要让他夸张地笑，也不要卡通鬼脸」；好「他嘴角只抬一点，眼睛没跟着笑，表情克制」。

## 5. 交付前自检清单（8 条）

1. 动作/状态词都能换算成画面变化吗？（PD-01）
2. shotSize 序列有无同主体直接接相邻两级？（PD-02）
3. 每镜 startPose/endPose 齐全、相邻承接、变化有合法过渡吗？（PD-03）
4. 每镜有独立光影句、光在动、逆光/反射有交代吗？（PD-04）
5. 现场声只写真实声源、无 BGM、声画对齐、跨镜连续吗？（PD-05）
6. 负向词只在排除表；行为/时序/状态都正写；双向检查过了吗？（PD-06）
7. 单镜动作事件 ≤2、信息唯一、主体焦点唯一吗？（PD-08）
8. 焦段与景别没有错配吗？（PD-09）

## 6. 边界与让位

- 草帽分镜技能可用时：**让位**，优先使用草帽的写作方法；本技能只在草帽不可用/用户要求兜底时使用。
- `drama-storyboard` 管分镜表结构与镜号规则；本技能管提示词写法。
- 资产/剧本类技能管资产卡与剧情台词；本技能不创造资产、不改台词内容。
- 判据门禁（checks）与本文档分离：代码侧默认 **WARN、不阻断**（v0.10.1 起）。

## 7. 版本与自检说明

- v1 判据对应 `证据/v0.10-判据候选清单-2026-10-18.json` 的 **PD-01/02/03/04/05/06/08/09**（06 草帽九项中除 POV 外的八项，依 PM/Lead 指定）。
- 全部为自写定义/自写示例，不复制草帽原文；交付前用 `_recover/verify-skill-draft-overlap.mjs` 做字符级最长公共子串自检（语料：草帽原文/06 分析/01–05/外部技能；阈值 ≤20 字；历史结果 max=19）。
- 后续 v0.10.1 判据机器化后，本清单与 `lib/checks.js` 新判据 id 一一对应：文本给写作侧，代码给门禁侧，避免双维护。
