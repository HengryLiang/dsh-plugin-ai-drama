# 短剧 BGM 配乐（Drama Music）

> 定位：为短剧设计**独立音轨**——逐场 cue 表（何时进/出、放什么、为什么）+ 可投喂音乐模型的 prompt blocks；管主题动机、情绪曲线、对白让位与跨集一致性。
> 边界：BGM 不写进分镜/镜头提示词（现场声/音效字段绝不含 BGM）；不做视频生成；不预测版权与平台审核结果；完整歌曲创作（歌词/唱腔）不是主路径。
> 音频产出：本技能只出配乐方案/prompt，**不保证插件能生成音乐**；音频由用户外部生成或现有工具导入。

## 1. 何时用 / 不触发

- **触发**：用户说 BGM / 配乐 / 背景音乐 / 主题曲 / OST / 片尾曲 / 音乐设计；要「这集/这场配什么音乐」；要主题动机、情绪曲线、音乐卡点、跨集音乐一致性；已有剧集要审配乐。
- **不触发**：单张图/分镜提示词（交对应技能）；纯音效、拟音、现场声（归分镜与提示词技能）；视频剪辑/生成；纯歌词创作、完整歌曲教程、唱腔教程（Suno 等平台操作与版本细节不教）；版权/授权判定；用户只要一首完整歌曲（可选但走 §9 简化路径，不是主路径）。

## 2. 输入（先读后写，缺则问）

- 读项目：`drama_get_project` 取契约（平台/单集时长/画幅）、大纲、人物与情绪弧线；`drama_read_episode` 取该集剧本；分镜/镜头时长用 `drama_get_ledger`（按集镜头数/时长），VSC/导演剖析与分镜片段用 `drama_search_context` 检索（构想区）——**读不到分镜就按剧本场次估时并标「≈估算」**，不得把手算当时码。
- 查已有音乐：`drama_list_assets` 里 kind=audio 的登记；已有 BGM/OST 能复用就不重复生成。
- 确认四件事：投放平台与单集时长；本集/本段场景功能（建置/冲突/反转/高潮/落点/结尾钩子）；情绪曲线（起→承→转→收，情绪名+强度 0–100）；是否已有主题动机/音乐身份。
- 关键信息缺失先问**一个**最必要的问题；不臆造时长、平台、情绪。

## 3. 输出 A：音乐总览 + 配乐 cue map（默认交付）

**3.1 音乐总览（先给）**：项目/集；整体听感方向（3–5 个参数词，如「低频克制、稀疏钢琴、干声近场」）；主题动机计划（MOTIF-A 用在哪条线）；BGM 密度（全片铺满 / 关键段 / 极简）；本集记忆点（建议 1–2 个）。

**3.2 cue map**：逐场/逐段一行，字段必须齐：

| 字段 | 写什么 |
|---|---|
| Cue ID | C1、C2…（一集内连续；MUS 建议沿用） |
| 集/场 | 集号/场号或段落名 |
| 入点 | 含进入方式（硬切/淡入/提前进入）＋`mm:ss` 或秒；估算加「≈」 |
| 出点 | 含退出方式（硬切/淡出/loop tail/硬停/提前收）＋`mm:ss` 或秒；估算加「≈」 |
| 时长 | 秒或 `mm:ss`；估算加「≈」，并校验不超过场景时长 |
| 是否需要音乐 | 是/否（否=静默，写理由） |
| 叙事/情绪功能 | 这场戏干什么＋观众该感受什么：情绪名＋强度 0–100 |
| BPM / 拍号 / 调式 | 数值＋术语（大调/自然小调/和声小调/五声/调式色彩） |
| 配器/织体 | 声音角色而非乐器清单：低频床/Drone/钢琴/弦乐/打击/合成器/民族乐器；旋律密度：无/短动机/完整主题 |
| 动态 | p/mp/mf/f、渐强/渐弱/渐慢/渐快 |
| 对白/音效策略 | 对白下压（ducking）、留白、让位现场声/关键音效、卡点 |
| 风险 | 抢台词/过煽/太满/重复/时长不够 |
| prompt | 对应 prompt 编号（见 §4，如 P1） |

另给 2–3 句「本集音乐弧线」：开头怎么起、高潮怎么推、结尾怎么收。

**要不要音乐（先判三问）**：①没有音乐这场是否仍成立？②音乐是否在替代本该由表演/音效承担的？③连续多段是否同一情绪？任一为「是」就考虑静默/减配；一集 BGM 覆盖率建议 50–70%（>70% 易疲劳），反转点与重要台词优先留空间。

## 4. 输出 B：生成用 prompt blocks（copy-ready）

以**目标平台实际字段**为准（Suno 等；不绑定任一平台，**不硬编未核实字段/模型版本/字符限制**）：

```text
Style: 流派/质感/配器/织体；instrumental（纯音乐，无人声/歌词）
Tempo: BPM＋拍感（4/4、6/8、free time）
Key/Mode: 调式＋色彩（大调/自然小调/和声小调/五声）
Mood→参数: 用音乐参数写情绪，不写「悲伤/高级/震撼」空词
Instrumentation: 角色化的配器（低频床/短动机钢琴/弦乐垫/稀疏打击…）
Dynamic arc: 从 p 到 mp、第 X 秒进入、结尾渐弱/硬停
Dialogue policy: under-dialogue / pauses only / no BGM / music-led
Negative: 具体排除（人声/歌词/大弦乐墙/密集鼓/明亮大调/过度混响…）
Duration: 目标≈Xs（平台不能精确控时长时写明用剪辑/loop 处理）
```

**参数翻译表（必须用）**：悬疑/不安→60–80、自然/和声小调、低频持续音、短动机、少旋律；悲伤克制→40–65、小调、钢琴单音、p–mp、留白；压迫/威胁→60–90、低八度持续音、不解决和声、稀疏打击；追击/燃→120–140+、4/4、清晰脉冲、打击与剪辑点对齐；温暖回忆→60–80、大调或五声、钢琴+弦乐垫、mf；荒诞/黑色幽默→中速、3/4 或不规则、干声、少混响。写不成参数的词一律换掉。
每个 cue 给 A/B 两版（A 贴合对白、B 情绪更强），只推荐一版并在 cue 表注明；B 版不得更满、更抢台词。

## 5. 主题动机、声音层级与转场

**声音层级（默认优先级）**：对白 > 现场声/关键音效 > BGM。BGM 不得盖过台词与关键音效；可只留低频床、降动态或直接静默；留白节点（反转前/重要台词后/情绪落点）优先给静默。

- **主主题 MOTIF-A**：3–5 音或一个节奏型即可；写清音程走向、节奏、音色、首次出现位置；后续用变奏（换配器/调式/速度/织体/缩短/倒影）表达不同情绪。
- **主题台账**：MOTIF / 用于哪些角色或关系 / 出现集数 / 时间码 / 变奏类型；跨集复用同一动机，**每集最多引入 1 个新主题**。
- **反转/高潮**：动机变形（停拍、不解决和弦、加张力）优先于「再加一层弦乐」；**结尾**：主题回归或留 unresolved（悬停/不解决），不要每集都大收束。
- **对白下压 ducking**：有台词处降动态/让出中频、必要时只留低频床或静默；重要台词前后留 0.5–2s 空间；BGM 不抢台词语气。
- **转场/卡点**：硬切（强转折）、淡出淡入（时间流逝）、停拍（反转前）、提前进入（预告下一场）；卡点对齐动作重音/台词落点/剪辑点，不硬凑节拍器。

**整剧 / OST 规划（可选）**：1 个主主题 + ≤2 个角色/关系主题 + 片尾曲 1（可选），不做「每角色一首」；每集音乐重心按类型分配（建置集少、冲突集中、高潮集多、落点集少而强）；OST/片尾曲给 30–60s 结构与方向即可，歌词按需，不承诺商用/发行。

## 6. 与资产系统（MUS 建议）

- cue 定稿后给 **MUS 资产建议**（只建议、**不自动登记、不写资产卡文件**）：建议 id（MUS###）/名称/用途（哪集哪些 cue）/时长/BPM/调式/参考文件/状态。
- 用户确认后，再由用户用现有资产工具登记：create（type=MUS、name）→ saveMedia 挂 `audio`（mp3/wav/m4a/ogg/aac，1–6 个 URL 或项目相对路径）；**不新造工具**。
- MUS 卡只写：用途、情绪/强度、时间码、BPM/调式、音频引用、版本；**不写生成提示词**（提示词留在 cue 文档）。
- cue map 落草稿：`drama_save_draft(kind=file, path='构想/配乐/EP<集>_cue.md')` → 用户采纳进正式目录；不覆盖正式稿。
- 音频先用现有素材/生成工具登记入库，再挂 MUS 卡；**未拿到音频前不得把 cue 表说成"已配乐"**。

## 7. 审片与交付前自检

1. **时长**：每 cue 起止落在场景时长内；总时长对上平台/集时长；估算标「≈」。
2. **情绪**：是否推动剧情而非重复画面情绪；强度曲线有起伏、有留白。
3. **台词**：有对白处是否让位（ducking/稀疏/静默）；重要台词前后有空间。
4. **音效/现场声**：是否为关键音效让位；不与现场声抢频段/抢注意力。
5. **重复**：同集主题使用是否过多；跨集是否复用同一 MOTIF（没有每集换新）。
6. **进出**：每次进入/退出都有理由，不是随机淡入淡出。
7. **参数**：prompt 是否量化（BPM/调式/配器/动态/negative），无空泛 mood 词。
8. **一致性**：BPM/调式/音色与项目音乐身份一致；OST 不跑偏。
9. **边界**：没把 BGM 写进分镜/镜头提示词；没承诺生成/版权/平台审核结果。
10. **有音频才评听感**：用户提供实际音频时，按 cue 表核对时长/情绪/ducking/重复并标「已听」；没听到只写「待听」，不编造听感。

## 8. 与其它技能分工

- **本技能**：BGM/配乐设计、cue map、prompt blocks、MUS 建议、配乐自检。
- **drama-director / drama-seedance-prompt / drama-shot-prompt**：画面与镜头提示词；它们的「现场声/音效」字段**绝不写 BGM**（现有硬规则），BGM 以本技能 cue 表为准。
- **drama-asset**：资产卡/参考图/门禁；MUS 卡走资产系统登记（本技能只给用途/情绪/时间码，不给生成提示词）。
- **drama-script / drama-episode**：剧本与台词；配乐不改变台词，只在留白处设计。
- **drama-visual-bible**：视觉风格；音乐身份与它并列（同一项目调性），可参考其五维调性但**不硬依赖**，也**不写进 style.json**。
- **roundtable**：可评审配乐方案/OST 方向；不替代本技能。

## 9. 边界与异常

- **完整歌曲/主题曲**（歌词+唱腔）：可选，非主路径；给简化 song brief（主题/情绪/结构/时长）即可，歌词与唱腔细节按需，不编造平台能力。
- **没有音频**：只给 cue 与 prompt；不描述「听到的效果」，不伪造音频/链接/任务 ID。
- **生成执行**：本技能只出配乐方案/prompt，**不保证插件能生成音乐**；插件 audio 分支用于配音等音频任务，不应当作音乐生成能力。音频产出由用户外部生成/现有工具导入；拿到音频后再用现有素材/资产工具登记，不伪造音频/链接/任务 ID。
- **不做完整歌曲教学**：不教 Suno 等平台操作/模型版本/歌词唱腔；只给配乐参数与 prompt 字段。
- **输出语言**：中文为主；prompt 字段可按目标平台语言（可英文），解释放字段外。
- **版权/参考**：可从参考曲提取鼓组/织体/调式/速度等「属性」，不复制旋律/歌词；参考≠授权。
- **时长不匹配**：给剪辑/loop/淡出方案，不硬改画面。
- **平台/时长不确定**：按集契约给建议区间并请用户确认；不硬套 60/90/120 秒，不把平台字段限制当永久事实。
- **不预测**：不预测商用可行性、平台审核、版权结果；不保证「像某片/某歌手」。

## 10. 最小示例

`EP01 00:00–00:20 建置｜≈20s｜功能=建置悬念｜情绪=不安 55→40｜动作=静默 3s→低频 drone 进入，18s 淡出｜BPM 68｜4/4｜和声小调｜配器=低频持续音+偶发钢琴单音（无完整旋律）｜p–mp｜对白：开场旁白下压，只留低频｜进出：淡入/28s 前淡出｜风险：太满压旁白`
对应 prompt（A 版）：`instrumental, slow 68 BPM, 4/4, harmonic minor, low drone bed, sparse single piano notes, no full melody, dynamic p to mp, leave space for narration, dark restrained tension, no vocals, no lyrics, no orchestral wall, no dense drums, target ≈20s`。
